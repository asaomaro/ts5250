# **継続欄（EDTMSK で割られた欄）で Erase EOF・Field Exit を打ったとき、ACS は続く区間まで消すか・欄を出た後のカーソルはどこか**（実機。2026-09-22）。
#
# 原典（ACS のコアの読み）: `PS5250.processEraseEOF` → `eraseToEOF_Work` は、カーソルの区間はカーソルから区間の終わりまで、**続く区間は全桁を** NUL にする。
# Field Exit・Field± も同じ消去を先に通る。欄を出る行き先は `FFT5250.nextNonByPassInputFieldPos` で、**継続欄の 2 区間目以降を飛ばす**ので、鎖の途中から出ても行き先は鎖の**後ろ**。
# 当 PJ は（変更前）カーソルの区間だけを消し、行き先は次の区間だった。**ここの「期待」は原典の読み。測定の結果は各節の dump で確かめる**。
#
# 画面は DTMPGM（`scripts/build-dttest.mjs`）の D8U（23,24。`EDTWRD('0   /  /  ')` + `EDTMSK('    &  &  ')` + 色・下線＝4 桁 / 2 桁 / 2 桁の 3 区間。区間の間は保護された `/`）。
# **`PROBE_ENPTUI=true` で流す**（拡張 5250 を申告しないと、ホストは欄を割らずに 1 つの 10 桁の欄として送る。`insert-no-room-continued.txt` と同じ）。
#   PROBE_ENPTUI=true node --env-file=.env --env-file=.env.verify scripts/acs-probe.mjs scripts/acs-probe/continued-field-erase-exit.txt

# **DBCS の欄（J・G・O・E）で、挿入モードのとき ACS は余地をどう数えるか**（実機の ACS のコア・社内機・930 で 2026-09-22 に通しで測定済み。`20260922-dbcs-insert-room`）。
# 台帳「挿入モードの余地の残り: DBCS 欄の『最終桁にカーソルなら空白でも余地なし』と、継続欄への IME 確定」の前半を測る。
#
# 原典 `PS5250.insertChar` は、打つ字の種類とカーソルのセルの種類（半角 / SO / SI / 全角の前半）で表 {前進, 必要桁, 操作列} を引き、
# `reserveRoomForInsert` が「欄の最終桁にカーソルなら即 0012」「そうでなければ**末尾から**カーソルまで、NUL・半角空白・全角空白（U+3000）が続く桁数を数え、
# SO/SI の桁で止まる。J・E（全角側）は末尾の SI の 1 桁手前から数える」で判定する（原典の読みを手元で書き起こして予測を立てた）。
# 各節の「予測」は原典の読み。**測定の結果**（すべて予測どおり）:
#   A1・A2: 成功（`う あ い □ □`・`あ い う □ □`）/ A3: 成功 / B1: J の SI の桁は inhibit=5（0012）/ B2: O の最終のセルは 0012 / B3: 1 桁手前は成功 /
#   C1: 成功 / C2: 0012 / C3・C4: 0012（**当 PJ は成功する。差が残る**）/ C5: 成功（X は A の直後。空の SO/SI が残るかは dump に SO/SI の桁が出ないので**未確認**）/ D1: 空白が全角空白になる / E1: 0012 / E2: 欄が作り替わる /
#   F1: O の末尾が全角空白の満杯欄は 0012（全角空白を空きに数えない）/ G1: 成功（G も全角空白を空きに数える）
#
# 画面は DSM の `DBCSFE`（`scripts/host-src/dscmd.c`。G=(3,10) / O=(5,10) / J=(7,10) / E=(9,10)、いずれも 12 桁・FFW 4008＝ME）を**そのまま**使う。
# 中身は手順の打鍵で作る（新しい画面は要らない）。ME は打鍵と挿入に関係しない。作り方: `DSCMD_PGM=DBCSFE` で scripts/build-dscmd.mjs（測った後に消す）。
#   J: 桁 10 = SO / 桁 11〜20 = 5 スロット（1 スロット 2 桁）/ 桁 21 = SI（`setcursor 7,10` は ECL が 7,11 へ動かす。SI の桁 7,21 には置ける）
#   G: 桁 10〜21 = 6 スロット（SO/SI 無し）  O・E: 桁 = セル
# 全角空白（U+3000）を打つには `keys` の行の**末尾を非空白にする**（`AcsProbe` は行を strip し、Java の strip は U+3000 も削る）ので、`[eof]` で止める。
# 半角空白 1 字を打つには、`keys` の後ろに空白を 2 つ書き、続けて別の字を置く（`keys  あ` = 空白 + あ）。
#
# 実行: node --env-file=.env --env-file=.env.verify scripts/acs-probe.mjs scripts/acs-probe/dbcs-insert-room.txt AS400
# 見る値: dump の `insert=true`（挿入モードになっているか）・`inhibit=5`（操作員エラー＝余地なし等）・カーソル・行の中身（SO/SI は文字面で確かめる）。
signon
keys [enter]
settle 1500
keys [home][eraseeof]ADDLIBLE ${LIB}[enter]
settle 1500
keys [home][eraseeof]CALL ${LIB}/KEYTST PARM('DBCSFE')[enter]
settle 3000
dump a0-initial

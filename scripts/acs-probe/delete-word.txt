# **Ctrl+Delete＝`[deleteword]`（ACS の既定 `C127`）は何を消すか**（実機の ACS のコア・社内機・930。2026-09-22）。
#
# 原典（ACS の既定のキー割り当て `AcsMapFunctions.MAP_5250` は `C127 = [deleteword]`。Ctrl+Backspace＝`C8` の割り当ては無い）。コアの `PS5250.processDeleteWord` →
# `processDeleteChar(…, true)` → `getDeleteCharacters` が「語」の範囲を数える。当 PJ は Ctrl+Delete を Erase EOF にしていた。
# **ここの「期待」は原典の読み**（R11 の調査）: カーソルが語頭なら「語＋後続の空白」、語の途中なら「カーソルから語末まで（後続の空白は残す）」、空白の上なら 1 字。
#
# 画面はサインオン直後のメニューのコマンド行（20,7 から）。文字は `keys` で打ち、`setcursor` でカーソルを置いて `[deleteword]` を打つ。
#   node --env-file=.env --env-file=.env.verify scripts/acs-probe.mjs scripts/acs-probe/delete-word.txt
signon
keys [enter]
settle 1500
dump menu

# **ME（必須入力）・MF（必須埋め）を ACS はいつ・何で判定するか**（実機）。
#
# 原典: `PS5250.processAIDCode` は AID の前に
#  1) カーソル下の欄が MF・MDT あり・満杯でも空でもない → 欄頭へ、エラー 20（0x14）
#  4) ME 欄のうち MDT の無いものがあり、**画面のどこかが変更済み（masterMDT）** → その欄へ、エラー 7。
#     ただし SOH で申告された F キー（CA キー）なら ME は見ない（`DS5250.isSOH_PF`）
# `FFT5250.checkMandatoryFieldCheck`。Tab 等で欄を出るときの MF の検査は `moveCursorWithMandFillCheck`。
# 当 PJ は Enter のときだけ・内容で判定している（`20260729-ffw-behavior-bits` D1）。推測で揃えず、ここで測る。
#
# 画面は ADJPGM（7,20=CHECK(MF) A 6 桁 / 11,20=CHECK(ME) A / 13,20=素の A）。F3 は CA03。
# 送れたかは `->` の右の写しで見る。各場合の終わりは Reset → Tab → F3 で抜け、`exit-*` がメインメニューで
# なければ次の場合は無効（`aid-without-field-exit.txt` の 1 回目の教訓）。実機にオブジェクトは作らない。

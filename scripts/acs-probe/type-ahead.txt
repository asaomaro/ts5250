# **施錠中（応答待ち）の打鍵を ACS のコアはどう扱うか**（実機。先打ち＝type-ahead）。
#
# 原典: `ECLPS.SendKeys` は施錠中・READ 待ちの打鍵を `keyBuffer` に溜め、解錠で再生する。
# `ECLPS.reset`（Reset）は施錠中なら溜めを捨てて解錠する。AID は `DS5250` の `pending_aid`。
# 既定は先打ち有効（`DISABLE_SESSION_TYPE_AHEAD` 既定 false）。
# ここで測るのは **ECL の `SendKeys` の経路**。ACS の GUI の打鍵がこの経路を通るかは別問題（未確認）。
#
# 施錠は `DLYJOB DLY(3)` の Enter で作る（応答が 3 秒来ない）。**各場合の `lock-*` が inhibit≠0 で
# なければ、その場合は無効**（施錠を作れていない）。実機にオブジェクトは作らない。
signon
keys [enter]
settle 1200

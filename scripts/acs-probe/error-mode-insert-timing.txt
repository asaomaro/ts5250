# **挿入モードが解けるのはエラーに入ったときか、抜けたときか**（実機）。あわせて、
# **エラーでないときの Reset でも挿入モードが解けるか**（原典 `ECLPS.reset` は常に解く）。
#
# `error-mode-exit-keys.txt` では「抜けた後に挿入モードが解けていた」までしか言えなかった
# （dump に挿入モードが無かった）。dump に `insert=` を足して、入った直後と抜けた直後を分けて見る。
# エラーの起こし方は同じ（単独欄 TOUSR を満杯にして挿入）。実機にオブジェクトは作らない。
# **`err-*` が inhibit=5 になっていなければ、その試行は無効**。
signon
keys [enter]
settle 1200
keys [home][eraseeof]SNDMSG[pf4]
settle 2000
keys [tab]
settle 600
keys ABCDEFGHIJ
settle 800

# --- 1) エラーに入る前・入った直後・抜けた直後 ---
setcursor 12,40
settle 400
keys [insert]
settle 400
dump ins-before-error
keys X
settle 900
dump err-entered
keys [right]
settle 700
dump after-right-exit

# --- 2) エラーでないときの Reset ---
setcursor 12,40
settle 400
keys [insert]
settle 400
dump ins-no-error
keys [reset]
settle 700
dump after-reset-no-error

# 後始末
keys [reset]
settle 600
keys [pf12]
settle 1200
keys [home][eraseeof]SIGNOFF[enter]
settle 1500

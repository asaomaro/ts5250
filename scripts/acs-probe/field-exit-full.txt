# **Field Exit 必須の欄を満杯まで打ったあと、ACS はどう振る舞うか**（実機）。独立点検の指摘を実機で確かめる。
#
# 原典 `PS5250.processCharKeyStroke`: 最終桁（符号付き数値は符号桁の手前）まで打つと `fieldExited` を立て、
# カーソルは最終桁に留まる。そこでさらに打つと `setErrorCode(24)`。文字以外のキーの後は `fieldExited` が下りる。
# Backspace 等で欄が変わると `setMDT` が `fieldExitReqFlag` を下ろすので、そのまま Enter は 0020 になるはず。
#
# 画面は ADJPGM（`scripts/build-adjtest.mjs`。3,20=CHECK(RZ) A / 11,20=CHECK(ME) A / 13,20=素の A /
# 15,20=CHECK(RZ) 6 0 / 19,20=6S0）と ULKPGM の DUP（`scripts/build-ulktest.mjs`。5,20=CHECK(RZ) DUP /
# 7,20=素の A / 9,20=CHECK(ER) DUP）。Enter の場合は ME 欄を先に埋める。
# 場合の終わりは Reset → Tab → F3。`exit-*` がメインメニューでなければ次の場合は無効。
signon
keys [enter]
settle 1200
keys [home][eraseeof]ADDLIBLE ${LIB}[enter]
settle 1500

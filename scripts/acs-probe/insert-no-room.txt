# **挿入モードで欄に余地が無いとき、ACS はどう振る舞うか**（実機）。台帳「挿入モードで欄が満杯のとき、あふれた末尾の文字を黙って捨てる」。
#
# 原典 `PS5250.insertChar` → `reserveRoomForInsert`: カーソルが欄の最終桁なら余地なし。そうでなければ
# 最終桁（符号付き数値は符号桁の手前）からカーソルまで、**末尾に続く空白**だけを数え、足りなければ余地なし。
# 余地なしは `setErrorCode` の 0x12（0012）で、値は変えない。行またぎの欄は位置が連続なので欄全体で数えるはず。
#
# 画面はメインメニューのコマンド行（20,7 から 153 桁＝21,79 まで。行をまたぐ素の英数字欄）と、
# ADJPGM（`scripts/build-adjtest.mjs`。19,20 = 符号付き 6S0 で、数字 6 桁＋符号桁の 7 桁）。
signon
keys [enter]
settle 1500
dump menu

# --- I1) 途中まで入った欄の先頭に挿入（末尾に空きがある）→ 押し出す ---
keys [home][eraseeof]ABC
settle 300
keys [home][insert]X
settle 300
dump i1
keys [reset]
settle 300
dump i1-reset

# --- I2) 空の欄の最終桁（空白）に挿入 → 最終桁なので余地なし（のはず） ---
keys [home][eraseeof]
settle 300
setcursor 21,79
settle 200
keys [insert]
settle 200
dump i2-before
keys Y
settle 300
dump i2
keys [reset]
settle 300
dump i2-reset

settle 300
setcursor 20,7
settle 200
keys [insert]
settle 200

keys Z

settle 300

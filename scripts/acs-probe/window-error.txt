# **ホストの妥当性検査エラー（WRITE ERROR CODE / TO WINDOW）で ACS はどう振る舞うか**（実機）。
#
# `scripts/build-ulktest.mjs` の ULKPGM:
#   RANGE  — 全画面の RANGE(1 5) 欄に 9 を入れて Enter → システムが WRITE ERROR CODE で返す見込み
#   WINDOW — 窓（WINDOW キーワード）の中の RANGE(1 5) 欄に 9 → WRITE ERROR CODE TO WINDOW の見込み
# 原典 `DS5250.processWriteErrorCode` はエラー状態に入り（`setErrorMode(true)`）、メッセージ行へ書く。
# 見るもの: メッセージがどこ（どの行・窓の中か）に出るか、inhibit、文字を打ったとき、右矢印で抜けたときの最下行。
signon
keys [enter]
settle 1200

keys [home][eraseeof]CALL ${LIB}/ULKPGM PARM('RANGE')[enter]

keys 3

dump r-char
keys [left]

dump r-left
keys [pf3]

# **O（DBCS open）欄の編集をセルの並びで測る**（ACS のコア・社内機。`20260928-o-field-cells`）。
# 原典 `PS5250.inputChar` / `insertChar` / `processDeleteChar` / `processBackspace` / `eraseToEOF_Work` の読みから作った表（`packages/web-ui/src/composables/oFieldCells.ts`）を、
# ホストが受け取ったバイト列（/tmp/dscmd.log の `[O1]`〜`[O3]`）で確かめる。画面は DSM の OEDIT（(3,10)〜(17,10) に O 12 桁を 8 つ。データは 10〜21 桁）。
# 各行の終わりのコメントは、表から立てた予測のバイト列。エラーの行は Reset してから次へ。測った後に DLTPGM と IFS の /tmp/dscmd.c・/tmp/dscmd.log を消す。

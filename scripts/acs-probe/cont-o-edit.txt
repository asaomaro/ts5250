# **継続欄の O の編集を巡ごとに測る**（実機の ACS のコア。台帳「継続欄の O」）。DSM の CONTOX（`scripts/host-src/dscmd.c`）:
# (5,10) 先頭 8 桁 `SO あい SI X`＋埋め / (6,10) 中間 8 桁 `YZ`＋埋め / (7,10) 最終 8 桁（空）。巡ごとに画面を書き直し、1 巡に 1 件だけ打鍵して Enter。
# ホストが受け取った READ MDT のバイト列は /tmp/dscmd.log の `[C01]`〜`[C12]`。CONTO の画面の読み（cont-o-insert.txt）が原典の読みと食い違ったので測り直す。

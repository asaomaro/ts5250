# **継続した O 欄の単独の SO/SI での Delete・Backspace**（実機の ACS のコア。台帳「継続した O 欄の残りの差」(d)）。DSM の CONTOX（`scripts/host-src/dscmd.c`）:
# (5,10) 先頭 8 桁 `SO あい SI X`＋NUL / (6,10) 中間 8 桁 `YZ`＋NUL / (7,10) 最終 8 桁（空）。巡ごとに画面を書き直し、1 巡に 1 件だけ打鍵して Enter。
# ホストが受け取った READ MDT のバイト列は /tmp/dscmd.log の `[C01]`〜`[C12]`。
# 作り方: DSCMD_LIB=<AS400_LIB> node --env-file=.env --env-file=.env.verify scripts/build-dscmd.mjs（**測った後に DLTPGM と /tmp/dscmd.c・/tmp/dscmd.log を消す**）。PROBE_ENPTUI=true で流す。
#
# 実行: PROBE_ENPTUI=true node --env-file=.env --env-file=.env.verify scripts/acs-probe.mjs scripts/acs-probe/cont-o-lone-shift.txt AS400

keys [enter]
settle 1500

settle 400

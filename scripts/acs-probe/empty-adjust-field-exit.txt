# 何も打たない右寄せ（CHECK(RZ)/CHECK(RB)）の欄で Field Exit（ACS のコア。独立点検 B-S6）。
# 原典 `PS5250.performRightAdjustFill` の読み: 欄末尾から NUL の数を数え、全桁が NUL なら全桁を埋め字（RZ は '0'・RB は空白）で埋める。
# 当 PJ は「全桁が空白の欄は整形しない」だった（根拠は tn5250 の無限ループ回避）。ACS が実際に全桁を埋めるかを測る。
# 画面は ADJPGM（既にあるもの。実機にオブジェクトは作らない）: 3,20 = CHECK(RZ) A / 5,20 = CHECK(RB) A / 7,20 = CHECK(MF) A /
#   11,20 = CHECK(ME) A / 13,20 = 素の A / 15,20 = CHECK(RZ) 6 0 / 17,20 = 素の 6 0 / 19,20 = 符号付き 6S0。受信値は各行の 34 桁目に `[...]` で写る
signon
keys [enter]
settle 1200
keys [home][eraseeof]ADDLIBLE ${LIB}[enter]
settle 1500
keys [home][eraseeof]CALL ${LIB}/ADJPGM[enter]
settle 2500
dump start

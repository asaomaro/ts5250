# **語送りの欄（FCW 0x8680）に打ったとき、ACS は欄をどう組むか**（台帳「継続した O 欄の残りの差」(b)。`PS5250.processWordWrap`）。
# DSM の WRAPFLD（`scripts/host-src/dscmd.c`）。(5,70) から 30 桁の欄（5 行目の 11 桁＋6 行目の頭から 19 桁）。巡ごとに打って dump（画面とカーソル）を採り、Enter で
# READ MDT ALT（W7 だけ READ MDT）を読む。ホストが受け取った欄のバイト列（NUL は 00・空白は 40）は /tmp/dscmd.log の `[W1]`〜`[W8]`。
# 作り方・後片付けは cont-o-edit.txt と同じ。実行: PROBE_ENPTUI=true node --env-file=.env --env-file=.env.verify scripts/acs-probe.mjs scripts/acs-probe/word-wrap.txt AS400
signon
keys [enter]
settle 1500
keys [home][eraseeof]CALL ${LIB}/DSCMD PARM('WRAPFLD')[enter]

# W1: 語の途中で行末になる（aaa bbbb cccc dddd）
keys aaa bbbb cccc dddd
settle 300

keys one two three four five six
settle 300

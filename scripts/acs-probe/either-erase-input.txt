# **Erase Input の後の DBCS の欄を ACS は何で送るか**（実機の ACS のコア。`20260927-either-field-so`）。DSM の READDBCS（`scripts/host-src/dscmd.c`。9 欄とも MDT あり）で、0x82 の待ちで Erase Input（`[erinp]`）→ Enter。
# 結果（2026-09-28。ホスト側のログの QsnRtvDta）: O・G の欄は何も送らない、J 欄（15,10）は `0e`＋NUL 10＋`0f`、全角の状態の E 欄（17,10）は `0e`。

# **欄を出ないまま AID を押したとき、ACS は送らずに操作員エラー（0020）にするか**（実機）。
#
# 原典 `PS5250.processAIDCode`: カーソル下の欄が 符号付き数値／CHECK(RZ)／CHECK(RB) で、
# MDT が立ち、`fieldExitReqFlag` が下りていて（打鍵で下り、Tab・カーソル移動・Field Exit で立つ）、
# `fieldExited` でなく、自動 Enter 欄でもなければ `setErrorCode(32)`（＝0x20）で送らない。
# 条件が込み入っているので、推測で決めずに場合分けして実機で押す。
#
# 画面は ADJPGM（`scripts/build-adjtest.mjs`。3,20=CHECK(RZ) A / 5,20=CHECK(RB) A /
# 11,20=CHECK(ME) A / 13,20=素の A / 15,20=CHECK(RZ) 6 0（初期値 000000）/ 19,20=6S0）。
# 送れたかは `->` の右の写し（`[`/`]` は CCSID で化けて見える）と、エラー（inhibit=5）で見る。
#
# ⚠ **1 回目の取り方は無効だった**: CHECK(ME) 欄が空だと Enter が ME エラーで止まり、
#   場合の終わりの F3 が 0020 で弾かれて次の CALL が欄へ打ち込まれ、以降が全部持ち越しで汚れた。
#   → Enter の場合は **先に ME 欄を埋める**。場合の終わりは **Reset → Tab（欄を出る）→ F3** とし、
#   **`exit-*` の dump がメインメニューでなければ、次の場合は無効**。実機にオブジェクトは作らない。

# **SysReq の行を出している間に届いた WTD を ACS は止めるか**（実機の ACS のコア。`20260927-sysreq-line-hold`）。DSM の LATEWTD（`scripts/host-src/dscmd.c`）:
# 画面 → 8 秒 → WTD（5,2 に LATE）→ READ MDT。待つ間に SysReq で行を出し、LATE が届いた後に dump（5 行目が空なら止めている）→ Reset で行を閉じて dump。
# 作り方: DSCMD_LIB=<AS400_LIB> で scripts/build-dscmd.mjs（**測った後に DLTPGM と /tmp/dscmd.c・/tmp/dscmd.log を消す**）。
#
# 実行: node --env-file=.env --env-file=.env.verify scripts/acs-probe.mjs scripts/acs-probe/sysreq-line-hold.txt AS400
signon
keys [enter]
settle 1500
keys [home][eraseeof]CALL ${LIB}/DSCMD PARM('LATEWTD')[enter]
sleep 2500
dump screen
keys [sysreq]
sleep 800
dump sysreq-open
sleep 9000
dump late-arrived
keys [reset]
sleep 1500
dump after-reset
keys [enter]
settle 2000
dump end
keys [home][eraseeof]SIGNOFF[enter]
settle 1500

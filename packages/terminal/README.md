# @ts5250/terminal

5250 を**文字端末**（Windows Terminal・bash・tmux など）で操作する前面。接続と画面モデルは `@ts5250/tn5250`
（`Session5250`）を使い、ここは表示（ANSI）とキー解釈・制御だけを持つ。

```sh
ts5250-term --host <ホスト> [--tls] [--ccsid 1399] [--user U --password-env AS400_PASSWORD]
ts5250-term --replay packages/tn5250/test/fixtures/pub400-jobinfo.jsonl   # ホスト不要
```

現状（第 3 段）: 描画・AID 送信・フィールド移動に加え、文字欄と O 欄の編集（挿入／上書き・Delete・Backspace・
Field Exit・型の検査・O 欄の SO/SI 補完）。規則は web-ui と同じ `@ts5250/tn5250/edit/*` を呼ぶ。
第 4 段で継続欄（EDTMSK の区間の並び。1 つの欄として挿入・Delete・Backspace・Field Exit）・語送り欄・継続した O 欄（鎖）を足した。
第 6 段で J／E／G 欄（1 行に収まるもの。半角の空白は全角空白、E は最初の字で半角・全角が決まる）を足した。
**未対応**: 複数行にまたがる J／E／G・継続した J／E／G・継続した語送り欄・Field＋／Field−（欄に打とうとすると「未対応」と知らせて値を変えない）。
挿入は Insert キーまたは接頭キーの `i`。AID の送信で上書きへ戻る。
経緯と実測は `.aidev/works/20261014-terminal-ui/`。下線・桁区切りは画面定義（DDS）に従い、代替の見せ方は足さない。

DDS のグリッド罫線（GRDBOX / GRDLIN）は、文字の無いセルに罫線文字（─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼。太字・二重・点線・破線は専用の字）で描く（`render/grid.ts`）。ホストの色と線種の指定どおりに描き、ACS に合わせない（web-ui と同じ判断）。

## 画面表示の設定（上部のパネル）

web-ui の「画面表示」設定のうち端末で実現できるものを、画面の上に 1 行の操作パネルとして出す（`app/view.ts`）。
切替は接頭キー（既定 Ctrl+`]`）の次の文字。パネルには現在値が出る（端末が小さく 1 行足りないときは画面を優先して出さない）。

| キー | 設定 | 端末での見せ方 |
|---|---|---|
| g | 罫線の表示 | DDS のグリッド罫線・窓の枠。文字のある行の横罫は罫線文字にせず上線（SGR 53）・下線（SGR 4）で引く。縦罫は文字のあるセルに重ねられない |
| t | 罫線の上辺 | 上線（既定。Windows Terminal で描かれることを確認）か、上の行の下線。上線に対応しない端末は下線を選ぶ |
| o | SO/SI 表示 | なし → 薄目（淡色の `{ }`）→ 濃目 |
| k | 表示コード | 自動 → カナ → 英。生バイトを対の表で読み直す（web-ui と同じ規則） |
| u / b | カーソルの形・明滅 | DECSCUSR で端末のカーソルを変える。挿入中は下線 |
| l / m / f | ルーラー・形・固定 | カーソルの行と桁を薄い背景色の帯にする（十字・横・縦）。固定は出した時点の位置 |
| v | 桁区切り | 点線の下線の表示・非表示 |
| w | パネル | パネルの表示・非表示 |

取り込まないもの: マウスポインター・リンク化・配色・質感・フォント・窓の背景（端末側の設定や、端末が持たない概念）。

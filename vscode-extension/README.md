# ts5250 for VSCode

IBM i（AS/400）の **5250 エミュレーター・プリンター・スプール表示・SQL・IFS** を、VSCode のエディタータブの中で使う拡張機能です。
接続先は小さな設定ファイルに書き、ファイルを開くとその機能の画面が開きます。**機能の種類は拡張子で決まります**（`.ts5250emu` ならエミュレーター、など）。

- 接続先ごとに設定ファイルを作っておけば、エクスプローラーからダブルクリックで開けます
- 空のファイルを作って開けば、あとは画面の欄で設定できます（「保存」でファイルに書きます）
- パスワードは暗号化してファイルに保存します（平文では保存しません）
- 別途 Node.js をインストールする必要はありません（VSCode 同梱の実行環境で動きます）

## 動作環境

- VSCode 1.90 以降
- 接続先の IBM i（TN5250 / ホストサーバー）へ、この PC から直接つながること

## インストール

Marketplace には公開していません。リポジトリのルートで `.vsix` を作り、VSCode に入れます。

```sh
./vscode-extension.sh          # Windows は vscode-extension.bat
code --install-extension vscode-extension/ts5250-vscode-0.1.0.vsix
```

VSCode の「拡張機能」ビューの「…」→「VSIX からのインストール…」でも入れられます。
入れ直したときは、開いている **すべての** VSCode ウィンドウで「Developer: Reload Window」を実行してください。

## 使い方

1. 開きたい機能の拡張子で**空のファイル**を作ります（例: `本番機.ts5250emu`）。拡張子は下の表のとおりです。
2. ファイルを開くと、接続前の画面が出ます。機能の種類・説明と、設定の欄が並びます。
3. ホスト・ユーザー・パスワード等を入力し、「**保存**」を押すとファイルに書き込まれます
   （ファイル名の横に「未保存の変更があります」→「保存しました」と出ます）。
4. 「接続」（スプール・SQL・IFS は「開く」）を押すと、その機能の画面に切り替わります。
   **未保存の変更があれば、保存してから接続します。**

ファイルを開いただけ・設定を変えただけでは接続しません。接続はボタンを押したときだけです。
ポートの値が正しくない間は、「保存」も「接続」も押せません。

### 機能の種類（拡張子）

| 拡張子 | 画面 | ボタン | 内容 |
|---|---|---|---|
| `.ts5250emu` | 5250端末 | 接続 / 切断 | IBM i の 5250 画面を操作します。3270（メインフレーム）にも切り替えられます |
| `.ts5250prt` | プリンター | 接続 / 切断 | ホストのプリンター装置として待ち受け、届いた帳票を表示します |
| `.ts5250spl` | スプール | 開く / 閉じる | スプールファイルの一覧・表示 |
| `.ts5250sql` | SQL | 開く / 閉じる | SELECT を実行して結果を見ます。CSV でダウンロードできます |
| `.ts5250ifs` | IFS | 開く / 閉じる | IFS のフォルダーとファイルを見ます |

種類を変えたいときは、ファイルの拡張子を変えてください（中身の設定はそのまま使えます）。

- **エミュレーターとプリンター**は装置（セッション）をつかむので「接続」「切断」があります。
  接続中はヘッダーの左に名前（ファイル名）と ⓘ（接続情報）が出ます。
- **スプール・SQL・IFS** は操作のたびにつないで閉じるので「開く」だけです。「閉じる」で設定の画面へ戻ります。
- 設定を変えたいときは「切断」／「閉じる」で接続前の画面へ戻り、欄を編集してからもう一度接続してください
  （接続中の画面から設定は開けません）。

### 画面の操作

- **⬇ HTML**（エミュレーター）: 今の画面を、見えているとおりの HTML ファイルとして保存します。
- **⚙ 表示**（エミュレーター・プリンター・スプール）: 文字の大きさ・色などの表示の設定。
- **外観**: 配色（端末: 5250 端末 クラシック等 / Web アプリ）と表示モード（通常 / ダーク / システム）の切り替え。

## 設定ファイルの中身

中身は JSON です（空のファイルは「何も設定していない」として開けます）。ふだんは接続前の画面の欄で編集すれば足ります
（テキストとして直接書き換えても、開き直さずに画面へ反映されます）。次は `.ts5250emu` の例です。

```json
{
  "host": "AS400",
  "port": 23,
  "tls": false,
  "ccsid": 930,
  "katakanaVariant": "katakana-ex",
  "terminal": "5250",
  "deviceName": "QPADEV0001",
  "screenSize": "24x80",
  "watermark": { "text": "検証機 {host}" },
  "signon": { "user": "USER", "passwordEnc": "v1:…" }
}
```

| キー | 対象 | 意味 |
|---|---|---|
| `host` | すべて | ホスト名または IP アドレス |
| `port` | 端末 / プリンター | Telnet のポート。省略すると平文は 23、TLS は 992 |
| `tls` | すべて | `true` で TLS 接続。省略時は TLS なし |
| `ccsid` / `katakanaVariant` | すべて | ホストコードページ。画面では一覧から選びます（930 は「カタカナ」と「拡張カタカナ」を `katakanaVariant` で区別） |
| `signon.user` | すべて | ユーザー |
| `signon.passwordEnc` | すべて | 暗号化したパスワード。**画面のパスワード欄から入れてください**（手で書くものではありません） |
| `terminal` | 端末 | `5250`（既定）/ `3270` |
| `screenSize` | 端末 | `24x80`（既定）/ `27x132`（5250 のみ） |
| `deviceName` | 端末 / プリンター | 装置名。端末は省略すると自動。**プリンターはほぼ必須**（多くのホストはプリンター装置の自動構成を許しません） |
| `watermark` | 端末 | 画面に重ねる透かし文字（本番機と検証機の見分け等）。`{host}` `{port}` `{device}` `{user}` などを差し込めます |
| `enhanced` | 端末 | 拡張 5250 GUI（ウィンドウ・選択フィールド・スクロールバー）を申告する。画面の欄には無く、ファイルでだけ指定します |

JSON として読めないファイルは、エラーを表示して設定の欄を出しません
（壊れたファイルを上書きしないため）。直すか、中身を空にしてから開き直してください。

## パスワードの扱い

- パスワードは **AES-256-GCM で暗号化**して `signon.passwordEnc` に保存します。
- 暗号の鍵は VSCode の SecretStorage（OS の資格情報ストア）に、この拡張機能専用に 1 つだけ作られます。
  **鍵はファイルに入らない**ので、設定ファイルを別の PC にコピーしてもパスワードは復号できません
  （その PC で入れ直してください）。
- それでも、暗号文を含む設定ファイルを Git 等にコミットしないことをおすすめします。

## しくみ

- 拡張機能は、この PC の中だけで動くサーバー（`127.0.0.1`、34000 番台の空きポート）を裏で起動し、
  画面はそのサーバーの Web 画面を VSCode のタブに表示しています。
- サーバーはすべてのウィンドウで 1 つを共有し、設定ファイルのタブがすべて閉じられると止まります。
- サーバーの起動状況やエラーは、「出力」パネルの **ts5250** に出ます。うまく開けないときはまずここを見てください。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「サーバーを起動できませんでした」と出る | 「出力」パネルの **ts5250** を確認してください |
| 拡張機能を入れ直したのに画面が古いまま | 開いているすべてのウィンドウで「Developer: Reload Window」を実行してください |
| プリンターが接続できない（自動構成の失敗） | `deviceName` にホストに作成済みのプリンター装置名を入れてください |
| 別の PC でパスワードが効かない | 鍵はその PC の SecretStorage にしかないため、パスワード欄から入れ直してください |

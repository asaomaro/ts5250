## 受け入れ基準ごとの検証

### 1. しきい値を接続時に指定できる — 合格

`DbConnectOptions.lobFieldThreshold`。丸めは `db-connection-lob-threshold.test.ts` で
境界を固定（未指定 / 0 / 負 / `NaN` / `Infinity` / 32,768 / 小数 / 上限 / 超過の 6 ケース）。

**`Infinity` は 0 に倒す**——「上限いっぱい」と読まない。上げる方へ倒すと静かにメモリを食う。

### 2. 列の型コードと行バッファの中身が実測で記録されている — 合格

`research.md` F1・F3。しきい値 65,536 で

- `SMALLC`（100/500 文字）→ **`type=408 CLOB` `len=1028`**
- `B`（5/2 バイト）→ **`type=404 BLOB` `len=1028`**
- `G`（3/6 文字・CCSID 1200）→ **`type=412 DBCLOB` `len=2052`**
- `BIGC`（100,000/150,000 文字）→ **`type=964 CLOB_LOCATOR` のまま**

生バイトも採った（`00 00 00 64` ＋ 100 バイトの `0x81`）。

### 3. `decodeValue` の 4 バイト読みが成立するか — **成立しない。ただし静かには壊れない**

**型コードごと変わる**ので、変更前のコードは
`HOST_SERVER_UNSUPPORTED: column "SMALLC" has unsupported type CLOB (408)` で**その場で落ちた**。
backlog が恐れていた「以降の列が全部ずれる」は起きない。

→ 4 バイト読みは**流用できない**ので、非ロケーター LOB 用の復号を新設した。

### 4. 往復数・応答バイト数の比較 — 合格

`SELECT ID, SMALLC, BIGC, B`（LOB セル 6 個）:

| 条件 | 往復 | 受信バイト |
|---|---|---|
| しきい値 0・取得なし（既定） | 4 | 982 |
| しきい値 0・中身を取得 | **12** | 132,757 |
| しきい値 65,536 | **4** | 5,078 |

### 5. 採否の判断と理由 — `decisions.md` D1

**採る。ただし既定は 0 のまま。**

### 6. 再現用スクリプト — 合格

`scripts/research-lob-threshold.mjs`（`scripts/README.md` に記載）。

### 7. 既存テストは無変更 — **2 件だけ更新した**

既定を変えていないので LOB の既存テストは通る。ただし
**「LOB 型は対象外」を宣言していた 2 件**（`db-types.test.ts` / `db-decode.test.ts`）は
**挙動を意図的に変えたので実態へ寄せた**。ロケーター型（960/964/968）が対象外であることは残し、
`db-decode.test.ts` の「対象外の型」は `XML` に差し替えた。

## 実機で踏んだ欠陥（自分の実装）

**DBCLOB の長さの単位を取り違えた。** 最初の実装は CLOB/BLOB と同じ「バイト数」として読み、
`日本語`（3 文字 / 6 バイト）を **`日`** に、`全角混在ab`（6 文字）を **`全角混`** にしていた。

**SBCS だけで確かめていたら通っていた**（文字数＝バイト数で見分けが付かない）。
全角で測り直して発見し、`chars * 2` に直した。単体テストは全角で固定してある。

## 未検証の穴

- **PUB400（7.5）では確認していない**（資格情報が無い）。往復削減の効果が最も大きいのは
  1 往復 4〜7 秒の PUB400 側なので、**効果の実測はまだ**
- **しきい値を実際に使う入口を作っていない**。`/api/host/sql` も MCP も
  しきい値を渡せない（spec の対象外）。**ライブラリとしては使えるが、アプリからは使えない**
- **大きなしきい値での応答サイズを測っていない**。今回は 65,536 のみ。
  過去の 8.4MB の実測（DBCLOB(2M)）は再現していない
- **ロケーター経由の DBCLOB が壊れている**ことが分かった（`research.md` F5）。
  バイト数が半分で、文字列に復号もされない。**本 work では直していない**（backlog へ）

# 要件: タブを切り替えても状態を失わない

## 背景 / 課題

利用者の指摘:

> WEB エミュレータ画面など一部の画面を除いて、別のタブを開くと状態が初期化されてしまう
> 機能がほとんどなのですが、不便なのですべてのタブで状態を保持するようにしてください。

`WorkspaceNode.vue` は 1 つのグループにつき **アクティブなタブのペインだけ**を描いている
（`v-if` / `v-else-if` の連鎖）。タブを切り替えると前のペインは**アンマウントされ**、
コンポーネントのローカル状態（`ref`）が丸ごと消える。

**5250 エミュレーターだけ無事に見えるのは、状態がコンポーネントではなく
`sessionsStore` にあるから**——再マウントしてもストアから描き直せる。
アプリ系のペインは自前の `ref` に持っているので、戻ると初期状態に戻る。

失っているものの例:

| ペイン | 消えるもの |
|---|---|
| SQL | 書いた SQL・クエリの並び・結果のタブ |
| IFS | いま居るディレクトリ・選択・編集中の本文 |
| ジョブ／オブジェクト／ユーザー一覧 | 絞り込み条件・取得した一覧 |
| スプール | 絞り込み・選択・プレビュー |
| データ転送 | ライブラリー／ファイル／WHERE・読み込んだ CSV |
| データ待ち行列 | 待ち行列名・送受信の内容 |
| 管理（ユーザー／セッション／ログ） | 取得した一覧 |

## 目的 / ゴール

**タブは切り替えても閉じるまで生きている。** 戻ったら、離れたときのままの画面が出る。

## スコープ

### 対象
- アプリ系タブ（`admin:` / `list:` / `sql:` / `ifs:` / `dtaq:` / `watch:` / `svc:` /
  `transfer:` / `spool:`）の状態保持。

### 対象外
- **5250 エミュレーター／プリンター**の描画方式は変えない。状態は既に
  `sessionsStore` にあり保持されている。画面（`ScreenGrid`）は 1 画面あたりの DOM が大きく、
  開いているセッションぶん常時マウントすると重くなるだけで得がない。
- タブを**別のグループへ移した**ときの引き継ぎ（移動＝別の場所へ作り直し。現状どおり）。
- 状態の永続化（リロードをまたぐ保存）。今回は「開いている間」の話。

## 機能要件

- アプリ系タブは**一度開いたら、閉じるまでマウントされ続ける**（切り替えでは壊さない）。
- **一度も開いていないタブは作らない**——起動時に全タブぶんの問い合わせが飛ぶのは困る。
- **タブを閉じたら本当に片付ける**。SQL は結果セット（＝ホストの接続を掴んでいる）を返し、
  サービス一覧は定期取得を止める必要がある。
- **見えていないペインが裏で働き続けない**:
  - 待ち行列監視は**見えている間だけ**既読にする（隠れている間の到着は未読のまま）。
  - サービス一覧は**見えている間だけ**定期取得する。

## 非機能要件 / 制約

- 追加の依存を入れない（Vue の標準機能で組む）。
- タブを閉じたときに `onUnmounted` が確実に走ること（`<KeepAlive>` は閉じたタブの
  インスタンスをキャッシュに残すため、この要件を満たせない）。

## 完了条件 (受け入れ基準)

- [ ] SQL に文字を書いて別タブへ移り、戻ると**書いた内容が残っている**。
- [ ] IFS でディレクトリを移動して別タブへ移り、戻ると**同じ場所に居る**。
- [ ] 一度も開いていないアプリタブは**マウントされていない**（問い合わせが飛ばない）。
- [ ] タブを閉じるとそのペインはアンマウントされ、後片付け（SQL の結果セット解放）が走る。
- [ ] 待ち行列監視が隠れている間の到着は**未読のまま**残る。
- [ ] サービス一覧の定期取得が、隠れている間は**止まっている**。

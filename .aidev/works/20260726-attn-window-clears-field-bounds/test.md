## テストが本当に欠陥を捕まえているか

**先にテストを書き、修正前に落ちることを確認した。**

```
× **SOH でフォーマットテーブルが消えても下線は伸びない**
    → expected [ 11, 12, ..., 80 ] (70 桁) to deeply equal [ 11..16 ] (6 桁)
× フォーマットテーブルを消したあと別の場所に欄が定義されても、元の境界は残る
    → 同上
✓ 前提: フィールドがあれば下線は欄の終端で止まる         （基準線・最初から通る）
✓ CLEAR UNIT では境界も消える
✓ SAVE / RESTORE SCREEN で境界も退避・復元される
✓ 同じ開始アドレスの再定義で境界が新しい長さに追従する
✓ **新しい欄と重なる古い境界は捨てる**
```

**下線が 6 桁 → 70 桁に伸びる**という報告どおりの症状を数値で捉えている。

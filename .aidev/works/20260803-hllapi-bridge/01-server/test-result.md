## lint が見つけた抜け（修正済み）

`writeIntoField` が `user` を受けながら使っておらず、**読み取り専用のセッションへ
HLLAPI から書き込めてしまう**状態だった。画面や MCP で塞いでいる境界を横から破る形。

→ `assertWritable` を通すようにし（MCP の `send_key` と同じ）、**回帰テストで固定**した。

## 測っていないこと

- **HTTP 経由で叩いていない**（`callHllapi` の直接呼び出しまで）。`02-bridge` と親で行う。

  画面の書き換えは伴わない（`docs/HLLAPI.md` に明記する予定）。

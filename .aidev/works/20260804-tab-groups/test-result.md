## 実ブラウザ実測（`scripts/verify-browser-tab-groups.mjs`）

jsdom は `<style scoped>` を適用せずレイアウトも計算しないため、**高さの要件は単体テストでは
確かめられない**。ビルド済み CSS を素の HTML に当て、Chromium で実寸を測った。

```
タブ帯（グループなし）              28.00px
タブ帯（グループあり）              28.00px
タブ 1 枚（グループ外）            26.00px
タブ 1 枚（メンバー）             26.00px
チップ                      20.00px
RESULT: PASS
```

**グループの有無で 28.00px から動かない**（`--chrome-row-h` と一致）。メンバータブ自身も
26px のままで、装飾（背景・`box-shadow: inset`）がレイアウトを押し広げていないことを確認した。
このスクリプトは **IBM i への接続を必要としない**（他の `verify-browser-*` と違い、
ビルド済み CSS だけで完結する）。

## coding 中に見つけて直した不具合（2 件）

いずれも新規テストが先に捕まえたもの。

1. **ポップアップが閉じられなかった**——バックドロップのクリックがチップ（開閉のトリガ）まで
   伝播し、「閉じる → すぐ開き直す」になっていた。`InfoPopover` は `mousedown` しか止めておらず、
   タブの中に置く分には無害（親の click は `selectTab`）だが、**トリガの中に置くと破綻する**。
   バックドロップの `click` も止めて修正（`TabGroupMenu.vue`）。
2. **畳んだチップへ落とすと並びが入れ替わった**——先頭メンバーを起点に挿していたため、
   3 枚目が 2 番目へ割り込んでいた（`[s1,s3,s2]`）。チップへの追加は「このグループに足す」
   なので**末尾メンバーの隣**へ付けるよう修正（`PaneTabs.vue`）。

## 未検証の穴（deliver へ引き継ぐ）

- **実アプリでの D&D の手触り**は未検証。HTML5 の D&D は Playwright での自動化が困難で、
  今回の実ブラウザ検証は**寸法の実測に限った**。中央 40% の当たり判定・ドラッグ中の予告表示の
  見え方・折り返し時の見た目は、人が触っての確認が要る。
- **ライト/システムテーマでの色の見分け**は目視未確認（ダークのみスクリーンショットで確認）。
  `--tg-*` はライト側も定義済みで、`--sys-*` と同じ「暗い地では明度を上げる」規則に従っている。
- 永続化しない仕様のため、**リロード後の復元**は検証対象外（ワークスペースのレイアウト自体が非永続）。

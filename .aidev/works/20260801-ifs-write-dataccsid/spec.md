# 仕様: テキスト保存でタグを中身に合わせる

## 設計方針

### D1: 符号化に使った CCSID をそのままタグにする

`/api/host/ifs/write` のテキスト経路は `body.ccsid ?? 1208` で符号化している。
**同じ値を `dataCcsid` として渡す**。別の値を選ぶ余地は無い——
「中身と合わせる」が要件なので、符号化に使った値が唯一の正解。

### D2: バイナリ（base64）には渡さない

文字コードの概念が無い。65535（バイナリ）でタグ付けする案もあるが、
**それは別の判断**（既存のアップロード物の扱いにも影響する）ので本 work では触らない。

### D3: 既存ファイルの挙動は変えない（変えられない）

`dataCcsid` は新規作成時にしか効かず、置き換えでもタグは保たれる（research F3）。
**他人のファイルのタグを勝手に付け替えない**という望ましい性質なので、
これを回避してまで付け替えることはしない。

### D4: 偽の接続にもタグを記録させる

テストの `writeFile` は長さしか記録していなかった。**指定を落としても書き込みは成功する**ので、
長さだけ見ていると「中身と食い違うタグ」に気づけない。偽の接続が
`ccsid=…` まで記録するようにして、経路が渡していることをテストで固定する。

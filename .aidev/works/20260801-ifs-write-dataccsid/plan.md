# 計画: IFS の書き込みタグ

## subtask 分割の判定

**分割しない**。実装 2 ファイル・テスト 1・スクリプト 1。

## 実装方針

**先に実機で「`dataCcsid` が本当に効くか」を測る**。受け口があるだけで
未実測だったので、効かないなら設計から変わる。

## 作業順序と依存関係

1. **T1** 実機で 4 条件を測る（無指定 / 1208 / 1399 / 既存の上書き）
2. **T2** サーバーのテキスト経路で `dataCcsid` を渡す（依存: T1）
3. **T3** `writeFile` のコメントを実態へ（依存: T1）
4. **T4** 偽の接続にタグを記録させ、期待値を更新（依存: T2）
5. **T5** build / lint / test ＋ 実機の再確認（依存: 全部）

## リスク / 留意点

- **既存ファイルのタグを付け替えない**。実機で「上書きでも変わらない」ことを確かめてから進む
- **バイナリ経路を巻き込まない**。base64 とアップロードは触らない
- **テストが長さしか見ていない**と、指定を落としても緑のままになる。
  偽の接続にタグを記録させる（D4）
- 実機に置いたファイルは `finally` で消す

# 要件: 3270 で IBM i のファンクションキーを効かせる

## 背景 / 課題

**いま 3270 で繋ぐと F キーが実質使えない。** 実機で `PF3` を送ると
「**機能キーは使用できません。**」と返る。同じ画面に 5250 で F3 を送ると受理される。

送っているバイトは正しい——`f3 c7 c4 ff ef`（AID＋カーソル＋EOR）で、
受理される Enter（`7d c7 c4 ff ef`）と **AID しか違わない**。
端末タイプを 3278/3279・±E で振っても変わらない。

原因は **IBM i の対応表がこちらの想定と違う**こと。IBM i 自身が
「ヘルプ－ 3270 キーボード・マッピング」という画面を持っている（3270 で繋いで `PF2`）:

| 3270 キー | IBM i での機能 | | 3270 キー | 機能 |
|---|---|---|---|---|
| PF1 | 5250 ヘルプ・テキスト | | PF7 | 前ページ・キー |
| PF2 | 3270 ヘルプ・テキスト | | PF8 | 次ページ・キー |
| **PF3** | **画面の消去** | | PF9 | アテンション |
| PF4 | 画面の印刷 | | PF10 | 取り消し |
| PF5 | 表示属性 | | PF11 | システム要求 |
| PF6 | テスト要求 | | PF12 | レコード後退 |
| PF13〜PF24 | **F13〜F24** | | | |

> **PA1 ＋ PF1..PF12 → F1..F12**
> **PA2 ＋ PF1..PF12 → F13..F24**

つまり **F1〜F12 は「PA1 を押してから PFn」** であって、PFn ではない。

## 目的 / ゴール

**3270 で IBM i に繋いだとき、5250 と同じ感覚で F キーが使える。**
メインフレーム（z/OS / TK4-）の挙動は**一切変えない**。

## スコープ

### 対象

- **ホストが IBM i かを交渉で見分ける**
- IBM i のとき F1〜F12 を `PA1` ＋ `PFn` で送る（F13〜F24 は素の PF13〜PF24）
- IBM i のとき **Attn / SysReq / Help / Print** を通す（PF9 / PF11 / PF1 / PF4）
- **ページ送りは素の PF7 / PF8**（IBM i の「前ページ・キー / 次ページ・キー」）
- 使えないキーは**理由を言って断る**（黙って捨てない）

### 対象外

- 装置名（`DEVNAME`）——別項目。ただし**同じ見分けを使う**ので、
  そちらが短くなるよう見分けは共有できる形にする
- PA2 経由の F13〜F24（素の PF13〜24 で足りることを実機で確認済み）

## 実測（この作業の前に取った）

| 測ったこと | 結果 |
|---|---|
| `PA1` の直後にすぐ次のキーを送れるか | **送れない**。施錠される |
| 施錠が解けるまで | **31 ミリ秒**（ホストがすぐ戻す） |
| `PA1`→（解錠待ち）→`PF4` | **「活動ジョブ処理 (WRKACTJOB)」**＝F4 が効いた |
| `PA1`→`PF12` | メインメニューへ戻る＝F12 が効いた |
| 素の `PF13` | **「INFO 情報援助オプション」**＝F13。`PA2`+`PF1` と同じ |
| 素の `PF3` | **拒否** |
| IBM i は `DO TN3270E` を出すか | **出さない**（基本 TN3270 で繋がる） |
| IBM i は `DO NEW-ENVIRON` を出すか | **出す**（TK4- / z/OS は出さない） |

## 機能要件

- **F1〜F12**: IBM i なら `PA1` を送り、**解錠を待ってから** `PFn`。それ以外は素の `PFn`
- **F13〜F24**: どちらも素の `PF13`〜`PF24`
- **PageUp / PageDown**: 素の `PF7` / `PF8`（**F7 / F8 とは別物**として送る）
- **Attn / SysReq / Help / Print**: IBM i なら `PF9` / `PF11` / `PF1` / `PF4`。
  それ以外は**理由を言って断る**
- 解錠が来なければ**時間切れで断る**（黙って握らない）
- **判断は 1 か所**に置く。キーボード・状態バーのボタン・マクロが同じ道を通る

## 非機能要件 / 制約

- **メインフレーム側の挙動を変えない**（TK4- の試験が無変更で通ること）
- 既存 4,700 件超を壊さない
- **実機で確かめる**（IBM i で F3 / F4 / F12 / F13 が効くこと）

## 完了条件 (受け入れ基準)

- [ ] 交渉から IBM i を見分けられる
- [ ] 実機で **F3 が効く**（いまは「機能キーは使用できません」）
- [ ] 実機で F4（プロンプト）・F12（取り消し）・F13（情報援助）が効く
- [ ] ページ送りが効く
- [ ] Attn / SysReq / Help / Print が IBM i で通る
- [ ] メインフレーム（TK4-）では**素の PFn のまま**
- [ ] 実ブラウザで F キーが効く

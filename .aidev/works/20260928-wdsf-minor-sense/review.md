# レビュー: WDSF のマイナー構造体の否定応答

## タスク点検ログ
- (cross・委譲) [should] `wtd-applier.ts` の 0x50 外側ゲートが常に `len<=20` で、スクロール・バー付き選択欄の閾値（ACS `checkMajorLength` の 28）を見ていなかった——
  スクロール・バー付きで長さ 21〜28 の短い構造体が、マイナーを歩く開始位置（sf の外）に届かないまま `undefined`（正しい扱い）になっていた /
  対応: 外側ゲートもスクロール・バーの有無で 28／20 を切り替える（`wtd-order-sense.test.ts` に境界 2 件。変異で検出）
- (cross・委譲) [should]（テスト不足）メニューバーでない選択欄で、メニューバー専用のマイナー型 0x09 のガード（`isMenuBar &&`）が外れても
  全テストが通っていた——0x09 は非メニューバーでは無視される、という否定側が未検証だった / 対応: 非メニューバーの選択欄に 0x09 マイナー（メニューバーなら
  無効な長さ）を持たせ、`undefined` になることを確かめるテストを追加（変異で検出）
- (cross・委譲) [nit] スクロール・バー付きのテストのラベル「マイナー長 3 は無視」が実際の挙動（無視ではなく、その長さ 3 が否定応答の原因）と逆だった / 対応: 文言を直した

# 決定記録

## D1: 罫線マイナーの反復・間隔のバイト位置を検算し直した

- 背景: 最初の実装は「色(1)・反復(1)・間隔(1)」の並びで p+7=色・p+8=反復・p+9=間隔と置いたが、既存テストが通っても
  境界のテスト（反復・間隔が 0 のケース）を追加する過程で原典を検算し直すと、色の後ろに「予約」が 1 バイト挟まる
  （`processDefineGridMinor` の `++n; int n10 = ++n; ++n;` の 3 回の increment のうち、最初の `++n` が色バイトを、
  2 回目までの間の 1 バイトが予約を、それぞれ読まずに読み飛ばしている）ことが分かった
- 決定: p+7=色（skip）・p+8=予約（skip）・p+9=反復・p+10=間隔に直した
- 影響: `WDSF_GRID_REPEAT_SPACING` を検査する条件のオフセットが 1 バイトずれていたら見落とす崩れたマイナーがあった
  （直した後は単体テスト・変異検査（24 通り）とも通過）

## D2: 実機（DSM）での検証はこの work では行っていない

- 背景: 台帳の他項目（`20260928-wdsf-negative` 等）は実機の DSM で ACS のコアと突き合わせてから着地しているが、
  この work は新しい DSM モードを立てる時間を取れなかった
- 決定: 原典（デコンパイル済み ACS のコア）の直読だけで実装し、そのことを requirements/design に明記した。
  台帳には「実機は未検証」と残す
- 影響: 台帳の「WDSF の中の否定応答」は、実機で確かめるまで完全には閉じない

# 要件: ヘッダーの高さをタブ帯に揃える

## 背景 / 課題

利用者の指摘——「ヘッダーの高さを 2 行目のタブエリアと同じ高さに揃えてください。」

測ると **ヘッダー 45px / タブ帯 28px** で、17px の差があった。ヘッダーは
`padding: 8px 14px` ＋ ボタン高さ 28px、タブ帯は `padding: 1px` ＋ タブ 26px と、
**別々の作りで別々の高さ**になっていた。

## 完了条件 (受け入れ基準)

- [ ] ヘッダーとタブ帯の高さが一致する
- [ ] **片方を直したときにずれない**（同じ値を見る）
- [ ] ビルド・lint・テストが通る

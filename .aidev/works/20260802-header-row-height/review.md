# レビュー: ヘッダーの高さをタブ帯に揃える

## ラウンド 1（自己レビュー）

### 「揃える」は「いま同じ数字にする」ではない

両方に `28px` と書けば今日は揃う。しかし片方を直した人がもう片方に気づかず、また
ずれる——**同じ数字が 2 か所にある**のは、直前の `20260802-screen-margins` で
3 か所の重複に躓いたのと同じ形。

CSS には「別の要素と同じ高さ」を書く手段が無いので、**1 つの変数を両方が見る**形にした。

### ホストに繋がずに測った

タブ帯はアプリのペイン（サービス）を開けば出る。実機の装置は共有で、直前に
「装置が使用中」で 3 回詰まったので、**繋がずに済む測り方**を選んだ。

## nit（直していない）

- **`.topbar` は `height`（固定）で、`.tabs` は `min-height`。** タブ帯は行が増えうるが、
  ヘッダーは 1 行に収める前提。狭い画面で中身がはみ出すなら `min-height` へ変える。

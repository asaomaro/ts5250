# テスト結果: ヘッダーの高さをタブ帯に揃える

| 検証 | 結果 |
|---|---|
| `npm run build`（`vue-tsc` 込み）／ `npm run lint` | 通過 / エラー 0 |
| web-ui 全体 | **1,266 件通過 / 失敗 0**（フレーキーも出ず） |
| 測定 | **ヘッダー 45 → 28px**（タブ帯 28px と一致） |

## 測り方

**ホストに繋がずに測った。** タブ帯はアプリのペイン（サービス）を開けば出るので、
実機の装置を取り合う必要が無い。

```
前: {"topbar":45,"tabs":28,"tab":26,"topbarPad":"8px 14px"}
後: {"topbar":28,"tabs":28,"tab":26,"topbarPad":"0px 14px"}
```

## 未検証（穴）

- **エミュレーター用のボタン**（⌨ キー / HTML / マクロ / 画面）が出ている状態で撮っていない
  ——それらも `.theme-btn` なので 22px に揃うが、確かめてはいない。
- **狭い画面での折り返し**を撮っていない（ヘッダーが 1 行に収まらない幅のとき、
  `min-height` ではなく `height` を指定しているので中身がはみ出す可能性がある）。

# 計画: クライアント側とホスト側のメッセージを同じ形にする

1. `ScreenGrid` に `withShiftCodes`（既存の `isFullWidth` を使う）
2. `.opmsg` を整形後の文字列で描く
3. **実機で撮って確かめる**（SO/SI 表示 ON で保護域に打鍵）
4. 影響を受けるテストを直す

## リスク / 留意点

- **`wrapper.text()` は前後の空白を落とす**ので、「SO/SI が 1 桁を占める」検査には
  `textContent` を使う（実際に踏んだ）。
- 画面表示設定の通知にも同じ整形が掛かる。**意図した変化**なので、テストは
  新しい見え方に合わせる（数合わせにせず理由を書く）。

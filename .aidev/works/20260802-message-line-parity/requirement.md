# 要件: クライアント側とホスト側のメッセージを同じ形にする

## 背景 / 課題

`20260802-message-line` で置き場所は揃えたが、利用者から続きの指摘:

> メッセージの**表示開始位置**や **SOSI の表示**がクライアント側のエラーメッセージと
> ホスト側のエラーメッセージで違っています。**ACS では区別していません。**

比べると:

| | ACS | このアプリ（直す前） |
|---|---|---|
| ホスト側 | `{オプション} R{が正しくない。}` | `{オプション} R{が正しくない。}`（画面データなので同じ） |
| クライアント側 | `{画面の保護域にカーソルがある。}` | `カーソルが保護された区域にあるため入力できません`（**印なし・1 桁ずれ**） |

**ACS はクライアント側のメッセージも画面のテキストとして置く**ので、全角の前後に SO/SI が入り、
`{ }` 表示でもホストのメッセージと同じ見え方になる。こちらは自前の文字列をそのまま
出していたため、印が付かず開始桁もずれていた。

## 目的 / ゴール

**どちらのメッセージか、見ただけでは区別できない状態にする**（ACS と同じ）。

## 完了条件 (受け入れ基準)

- [ ] `{ }` 表示のとき、クライアント側にも全角の前後に印が付く
- [ ] 印を出さないときも **SO/SI の 1 桁が残る**（開始桁が揃う）
- [ ] 半角だけのメッセージには入れない
- [ ] ビルド・lint・テストが通る

# 要件: SCS の FF は中身が無くてもページを作る（ACS の JPS と同じ）

## 背景 / 課題
`.aidev/backlog/acs-parity.md` の【まとめ】SCS の解釈の差の「台帳に無かった差」: **空ページ**——ACS は FF ごとにページを作る（FF FF で空白の 1 枚）。当 PJ は空ページを出さない（`scs.ts` の `flushPage`。決定の記録なし）。

## 目的 / ゴール
FF で区切られたページの数が ACS の JPS と同じになっている状態。

## ユーザーストーリー
- US1: プリンターセッションの利用者として、ホストが白紙を挟んだ帳票でも ACS と同じ枚数で受け取りたい。なぜなら白紙が詰まると、ページ番号や裏表の揃えがずれるから。（受け入れ: AC1）

## スコープ

- `packages/scs/src/scs.ts` の `flushPage`
### 対象外
- 最後の FF の後ろ（ACS の JPS は印刷しないが、情報を捨てるので合わせない。台帳の方針どおり）

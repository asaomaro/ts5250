# レビュー記録

## ラウンド 1（自己レビュー）

### 着手前に潰したこと

- **案が没になる可能性を先に測った。** 「本物の窓が開いているとき背景の入力欄が残るなら、
  この条件は本物を殺す」——既存 fixture は `fields` を持たず答えられなかったので実機で測った。
  結果は**残らない**（窓が開くとホストが欄の一覧を差し替える）。案は生きていた。

### 注意して作ったところ

- **保護欄を見ない**（背景の見出しで切れてしまう）
- **欄の右端まで見る**（内側から始まって外へはみ出す欄を通さない）
- **差分判定（`introducedOutside`）より前に置く**（あちらは前画面がある時だけ働く補助）

### 限界（コード・テスト・backlog の 3 箇所に書いた）

- **欄が 1 つも無い画面には掛からない。** ヘルプ窓は入力欄を持たないことが多く、
  **これだけで ③ が全部消えるわけではない**

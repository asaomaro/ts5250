# 仕様

## D1. 掛ける場所

`detectWindowRect` の**候補が決まった直後**（罫線・反転のどちらで選ばれた候補にも掛かる）、
かつ**前画面との差分（`introducedOutside`）より前**。差分は前画面が渡されたときだけ働く
補助なので、常に効くこちらを先に置く。

## D2. 見るのは**入力できる欄だけ**

保護欄は見ない。背景の見出しや説明文は保護欄で、**枠の外に文字があるのは当たり前**——
それは窓を否定しない。「打てる欄が外にある」＝「ホストはまだ背景を触らせるつもり」＝窓ではない。

## D3. 欄の**右端まで**見る

`col + length - 1` が `col2` を超えたら外。左端だけだと、枠の内側から始まって外へはみ出す欄を
通してしまう。

## D4. 実機で裏を取る（この仕様の根拠）

2026-08-22 に実機（IBM i 7.3）で採取:

| 画面 | 入力欄 |
|---|---|
| メインメニュー（窓なし） | 1 個（コマンド行） |
| メインメニューの F1 ヘルプ窓 | 1 個（窓の内側） |
| WRKOBJPDM（背景） | **12 個**（見出し 3・オプション列 8・コマンド行 1） |
| その上に F1 ヘルプ窓 | **1 個だけ**（`r11c9` ＝ 窓の内側） |

**窓が開くとホストは欄の一覧を丸ごと差し替える。** 背景の欄は残らないので、この条件は
本物の窓を殺さない。

## D5. 限界を明記する

**欄が 1 つも無い画面には掛からない。** ヘルプ窓は入力欄を持たないことが多いので、
これは「効くときだけ効く」安価な補助。**これだけで ③ が全部消えるとは考えない。**
コードとテストの両方に書く。

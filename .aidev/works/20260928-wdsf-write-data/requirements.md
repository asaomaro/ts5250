# 要件: WDSF 0x54（欄へのデータの書き込み）を ACS と同じに効かせる

## 背景 / 課題
台帳「WDSF の中の否定応答」・「DS5250 の残り」の 0x54。当 PJ は警告して読み飛ばし、欄に何も書かなかった。ACS（`ENPTUI5250.processWriteData`）は欄を消して書き、形が違えば否定応答。

## 目的 / ゴール
0x54 の EBCDIC の形（flag 0x80）で、欄の中身・MDT・番地・否定応答が ACS と同じ状態。

## ユーザーストーリー
- US1: 0x54 で欄の値を書き換える画面の利用者として、ACS と同じ値が欄に出てほしい。なぜなら、書かれない欄では古い値のまま送ってしまうから。（受け入れ: AC1〜AC4）

## スコープ
### 対象
- flag 0x80: 欄の先頭で、欄（継続欄は区間の合計）に収まれば、欄を消して（MDT はそのまま）書く。継続でない欄は番地が書いたぶん進む。継続欄は区間の長さで割る
- 欄の先頭でない・flag が分からない → 0x10050140、長すぎる → 0x10050141
### 対象外
- CCSID の形（flag 0x40。Unicode のデータストリームだけ）・DBCS の継続欄の区間ごとの SO/SI の閉じ方（台帳に残す）

## 完了条件 (受け入れ基準)
- [ ] AC1: `OLDVALUE12` の欄に `NEW`＋続けて `Z` で `NEWZ`、MDT は立たない（単体・実機 D1）
- [ ] AC2: 欄の先頭でない番地は 0x10050140、欄より長いデータは 0x10050141（単体・実機 D2・D3）
- [ ] AC3: 3 区間の継続欄に `ABCDEFGHIJ` で `ABCD`/`EFGH`/`IJ`（単体・実機 D4）
- [ ] AC4: flag に 0x80・0x40 のどちらも無ければ 0x10050140（単体）

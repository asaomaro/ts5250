# 要件: 透過の欄（FCW 0x84xx）を ACS と同じ形で送る

## 背景 / 課題
`.aidev/backlog/acs-parity.md`「DS5250 の残り」の FCW 0x84xx: ACS `DS5250.sendAll` は透過の欄を加工せずに送る。当 PJ は FCW 0x84xx を読み飛ばし、普通の欄として末尾のヌルを落として送っていた。

## 目的 / ゴール
透過の欄の値が ACS と同じバイト列でホストへ届く状態。

## ユーザーストーリー
- US1: 透過の欄を使う画面の利用者として、打った値が ACS と同じ形でホストへ届いてほしい。なぜなら形が違うと、ホストの応用プログラムが受け取る値の長さと中身が ACS と変わるから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- FCW 0x84xx の読み取りと、READ MDT 系・READ INPUT 系の送信
### 対象外
- FCW 0x80xx（再順序付け）・WDSF 0x52/0x54/0x55・罫線の寿命（同じ台帳項目の残り）
- 透過の欄の打鍵の規則（ACS も普通の欄と同じ）

## 完了条件 (受け入れ基準)
- [ ] AC1: READ MDT 系（0x52・0x82・0x83）で透過の欄は `11 行 桁 10 長さ(2) 生バイト`（ヌルも落とさない）。FCW の下位バイトは問わない（実機・単体）
- [ ] AC2: READ INPUT 系（0x42・0x72）で透過の欄はヌルを空白に換えず欄長ぶん送る（単体。原典）

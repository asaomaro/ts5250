# 決定記録

## D1: IBMRSEED のゼロシード（ESC＋8 バイトの 0）を破棄する

- 背景: 以前の実装は「ゼロシードで非暗号化を示す」として ESC＋8 バイトの 0 を送っていた。エスケープされるのは先頭の 1 バイトだけで、残る 7 個の 0x00 は RFC 1572 では空の VAR。
- 決定: ACS の原典（平文では値を書かない）と ACS のワイヤ（F4）に合わせ、値なしにする。PUB400 で通ることを確かめた。

## D2: 手元の実機での確認は QRMTSIGN のため成り立たない

- 手元の実機は `*FRCSIGNON` で、自動サインオンを受けても必ずサインオン画面を出す。変更前の実装でも同じ結果だったので、この変更の良し悪しは PUB400 と ACS のワイヤで判断した。

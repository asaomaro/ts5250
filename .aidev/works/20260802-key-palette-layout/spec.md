# 仕様: キーの一覧を 2 行に収め、ファンクションキーを右寄せに

## 開いている間は常時行の顔ぶれを変える

```
閉: … 上書き            F1 F3 F4 F5 F12 ⏎  [▲ その他]
開: … 上書き   ⏎ Attn SysReq PageUp PageDown Home End Esc Ctrl Alt [▼ その他]
                                        F1 F2 … F24（右寄せ）
```

**同じキーを 2 か所に出さない**——一覧に F1〜F24 が全部出ているので、常時行の
`F1 F3 F4 F5 F12` は重複になる。確定キー（⏎）は一覧に無いので残す。

## 右寄せ

`justify-content: flex-end`。上の行の「その他」ボタンの側へ揃う。
狭い幅では折り返す（`flex-wrap: wrap`）。

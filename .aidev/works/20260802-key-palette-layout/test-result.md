# テスト結果: キーの一覧を 2 行に収め、ファンクションキーを右寄せに

| 検証 | 結果 |
|---|---|
| `npm run build`（`vue-tsc` 込み）／ `npm run lint` | 通過 / エラー 0 |
| web-ui 全体 | **1,266 件通過 / 失敗 0**（フレーキーも出ず） |
| 実機で撮影・確認 | 下記 |

## 実機で確かめたこと

**目視だけにせず、ボタンの顔ぶれを数えた**:

```
oiaKeys: ["⏎","Attn","SysReq","PageUp","PageDown","Home","End","Esc","Ctrl","Alt","▼ その他"]
padCount: 24
```

常時行からファンクションキーが消えて確定キー（⏎）が残り、Attn 以下が並んでいる。
一覧は F1〜F24 の 24 個だけで、右寄せになっている。**3 行 → 2 行**。

## 未検証（穴）

- **狭い幅での折り返し**を撮っていない。常時行が長くなったので、狭いと折り返して
  結局 2 行以上になる可能性がある。

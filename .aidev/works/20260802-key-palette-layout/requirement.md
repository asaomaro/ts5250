# 要件: キーの一覧を 2 行に収め、ファンクションキーを右寄せに

## 背景 / 課題

利用者の指示（`20260802-key-palette` の続き）:

> その他キー表示時、常時表示のボタンエリアから**確定キーは残してファンクションキーは消し**、
> **3 行目に表示している attn などのキーを並べて行を減らして**ください。
> ファンクションキー一覧は左寄せではなく**右寄せ**にしてください。

開いた状態が 3 行（OIA ＋ F1〜F24 ＋ その他のキー）になり、そのぶん画面が狭くなっていた。
また常時行の `F1 F3 F4 F5 F12` は、一覧に F1〜F24 が全部出ているので**同じキーが 2 か所**に
出ていた。

## 完了条件 (受け入れ基準)

- [ ] 開いている間、常時行のファンクションキーが消え、確定キー（⏎）は残る
- [ ] Attn などが常時行に並び、**2 行**に収まる
- [ ] ファンクションキーの一覧が**右寄せ**
- [ ] ビルド・lint・テストが通る

# 仕様

## 1. MCP の `host_sql`

**`allowWrite: true` を明示したときだけ**非クエリ文を通す。**接続する前に断る**。
応答は `kind` で見分ける（`"query"` / `"execute"`）。

⚠ **これは安全の境界ではない**——`host_command` の `RUNSQL` で同じことができる。
意図を毎回述べさせるためのもの。

## 2. ページング経路

**寄せない。** 読み切ったページはその場で接続を返しており、掴む問題は起きない。
寄せると「続きを読む」が成立しなくなる。振る舞いをテストで固定する。

## 3. LOB のしきい値

`/api/host/sql` と MCP `host_sql` に `lobThreshold`（上限 15MB）。

⚠ **接続時の属性なのでプールの鍵に混ぜる。** 混ぜないと別設定の接続を貸してしまい、
**指定が黙って効かない**。

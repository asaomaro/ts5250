# 要件: 設定フォームの見直し（利用者の指摘 4 件）

## 背景 / 課題

実際に使ってみての指摘:

1. **保管場所を select で選ばせている** → チェックボックスにしたい
2. **「サーバー設定（全員が使える）」は誤り** → 管理者にしか見えない
3. **PC コマンドの欄がシステム追加に出ている** → エミュレータセッション側で行うので不要
4. **「無操作で切る」に「サーバー既定に従う」がある** → サーバー単位で設定する必要が無いので削除
5. **チェックボックスがブラウザ既定の意匠**で他と合わない → トグルでも可

## 目的 / ゴール

**画面の表記と作りを、実際の振る舞いに合わせる。**

## スコープ

### 対象

- 保管場所をチェック 1 つに（表記も直す）
- 信頼設定の欄が**セッションカードにだけ**出るようにする
- 「無操作で切る」から「サーバー既定に従う」を外す
- チェックボックスの意匠

### 対象外

- 認可・保存の仕組み（表示と入力の形だけ）

## 事実確認

**`--idle-timeout` は起動オプションとして実在する**（`main.ts:197`）ので、
「サーバー既定に従う」は嘘ではなかった。ただし「サーバー単位で設定できる必要が無い」は
利用者の判断なので、**選択肢は外す**。手書きで未指定のままの定義には従来どおり効く。

## 完了条件 (受け入れ基準)

- [ ] 保管場所がチェック 1 つで、表記が「管理者だけが参照・編集できる」になっている
- [ ] システム追加に PC コマンドの欄が出ない（セッション側には残る）
- [ ] 「無操作で切る」に「サーバー既定に従う」が無い
- [ ] チェックがトグルとして描かれ、select・入力欄と揃っている
- [ ] ビルド・lint・テストが通る（意図の変わったテストは書き直す）

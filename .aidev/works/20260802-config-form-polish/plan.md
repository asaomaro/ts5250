# 計画: 設定フォームの見直し

## 作業順序と依存関係

1. 保管場所のチェック化（`isServerSource` の橋渡し）＋ 表記
2. 信頼設定 3 つに `kind === "session"` を足す
3. 「サーバー既定に従う」を外し、未設定の既定を「切らない」に
4. `styles.css` にトグルの意匠
5. **実ブラウザで撮って確かめる**（意匠は目で見ないと分からない）
6. 意図の変わったテストを書き直す

## リスク / 留意点

- **テンプレートに `**` は書けない**（そのまま文字として出る）。強調は `<strong>`。
- 既存テストが「サーバー既定に従う」「select」を前提にしている。**意図の変化として書き直す**。
- 意匠は全体に効くので、他のペイン（SQL・データ転送・待ち行列）も確認する。

## テスト方針

- **実ブラウザで撮る**（4 枚: システム新規・サーバー設定 ON・表示セッション・プリンター）
- 既存テストの書き直し（`config-card-idle-timeout` / `config-card-ownership`）

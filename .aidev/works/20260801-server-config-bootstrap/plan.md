# 計画: サーバー設定を画面から作り始められるようにする

## 作業順序と依存関係

1. `ServerConfigStore.fromFileOrEmpty`（個人設定と同じ形）
2. `main.ts` の既定パス（依存: 1）
3. **3 経路を実物で確かめる**（既定・打ち間違い・既存ファイル）（依存: 2）
4. `start.sh`（無ければ作る）（依存: 2）
5. `.gitignore` / README
6. 単体テスト（依存: 1）

## リスク / 留意点

- **打ち間違い保護を落とさない。** `fromFile` は投げるままにし、`fromFileOrEmpty` を別に足す。
- **既定の保存先に資格情報が入る。** `.gitignore` を同時に直さないと、公開リポジトリの
  作業ツリーに実運用の接続先が置かれる。
- `start.sh` は `--profiles` に渡す以上、**渡す前に作る**必要がある（渡してから無いと起動しない）。

## テスト方針

- **単体**: 空で始まる／保存でファイルができる／既存を読む／壊れていれば投げる／
  明示指定は無ければ投げる／**個人設定と同じ `persistable`**
- **実物**: サーバーを 3 通りで起動し、`GET /api/systems` の `editable` と中身を見る

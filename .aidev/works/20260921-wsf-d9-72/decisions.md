# 決定記録

## D1: Unicode の CCSID の申告も ACS と同じく返す

- フラグ 0x40 の応答は CCSID 13488・17584・1200 を申告する。当 PJ は Unicode の欄（FCW 0x90xx〜0x93xx＝CCSID・最大の戻りデータ長。ACS `Field5250` の `FCW_CCSID_*`）を扱わない（読み飛ばすだけ）ので、申告した後に
  ホストが Unicode の欄を送ってくると正しく扱えない恐れがある（**未確認**。台帳「DS5250 のその他の差」）。それでも応答しないとホストは
  待ち続けて施錠されたままになる（実測）ので、ACS と同じ応答を返す。ACS 自身もこの応答は Unicode の設定に関係なく返す（原典の条件はフラグだけ）。

## D2: フラグ 0x80 は返さない

- ACS は否定応答（センス・コード 0x10050112）を返す。当 PJ は否定応答を持たないので、警告だけ出して返さない（ホストは待つ——以前と同じ）。

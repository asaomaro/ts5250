# 要件: Field Exit 必須の欄を ACS と同じく扱う（RZ・RB・符号付き数値を含める）

## 背景 / 課題
ACS は右寄せ（RZ/RB）と符号付き数値の欄も Field Exit 必須として扱い、満杯でも次の欄へ自動送りしない。当 PJ は FFW の
FER ビットだけを見ていたので、RZ/RB を満杯まで打つと次の欄へ送り、自動 Enter 欄なら Enter まで送っていた。

## 目的 / ゴール
- 右寄せ・符号付き数値の欄を満杯まで打っても、**ACS と同じく欄に留まり、Enter は ACS と同じく通る／止まる状態**。

## ユーザーストーリー
- US1: 端末の利用者として、右寄せの欄を打ち終えたとき ACS と同じ位置にいたい。なぜなら次の欄へ勝手に移ると、
  続けて打った文字が別の欄に入るから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- 満杯での自動送り・自動 Enter・Dup の後の送り。最終桁まで打ったときの 0020 の扱い。
### 対象外
- 満杯で留まった欄での、さらなる打鍵（ACS は未測定）。

## 完了条件 (受け入れ基準)
- [ ] AC1: RZ・RB（自動 Enter 付きも）は満杯でも自動送り・自動 Enter をしない。
- [ ] AC2: RZ を最終桁まで打てば Enter が通る（場合 10）。符号付き数値は数字桁を埋めても 0020（場合 11）。
- [ ] AC3: 各判定を外すとテストが落ちる（`verify-by-mutation`）。

# 要件: 欄を出ないまま AID を押したら、送らずに操作員エラーにする（ACS の 0020）

## 背景 / 課題
右寄せ（CHECK(RZ)/(RB)）・符号付き数値の欄に打って、Field Exit を押さずに Enter を押すと、
当 PJ は**右寄せしないまま左詰めで送っていた**。英数字の RZ/RB 欄には `12    ` のまま格納される。
ACS は送らずにエラー 0020 にする（利用者の判断: ACS と同じくエラーにする。台帳「方針決定」）。

## 目的 / ゴール
- 右寄せ・符号付き数値の欄の値が、**右寄せされないまま黙ってホストへ届くことが無い状態**。

## ユーザーストーリー
- US1: 端末の利用者として、Field Exit を押し忘れたときに**気づきたい**。
  なぜなら左詰めのまま登録されると、後から直すのが難しいから。（受け入れ: AC1, AC2, AC3）

## スコープ
### 対象
- web-ui の送信前検査（0020）と、その前提になる「欄を出たか」の付け外し。
### 対象外
- RB/RZ/符号付き数値の欄を満杯でも自動送りしない（台帳の別項目）。
- ME/MF の意味とタイミング（別項目 ④）。

## 機能要件
- FR1: カーソル下の欄が RZ/RB/符号付き数値（自動 Enter 欄を除く）で、打ったあと欄を出ていなければ、AID を送らない。
- FR2: Help・Clear・フラグキー（Attn/SysReq）は止めない。Enter 以外の AID（F キー・Roll）は止める。
- FR3: 止めたら操作員エラー（エラー状態）にし、カーソルは動かさない。
- FR4: Field Exit / Field± / Dup・Tab 等でカーソルが欄を出る・Erase Input・新しい画面で、待ちを外す。欄の中の移動では外さない。

## 非機能要件 / 制約
- 規則は原典と実機の ACS に合わせる（research F1・F2）。文言は日本語・です・ます調・句点なし。

## 完了条件 (受け入れ基準)
- [ ] AC1: RZ・RB・符号付き数値の欄に打って欄を出ずに Enter / F3 / PageDown を押すと、送らずにエラーになり、カーソルは動かない。
- [ ] AC2: Field Exit・Tab で出て戻る・Erase Input・素の欄・未入力・自動 Enter 欄・Help / Clear では送れる。欄の中の右矢印では送れない。
- [ ] AC3: ペインを通らない送信（OIA のボタン）でも止まり、エラー状態に入る。新しい画面で待ちが消える。
- [ ] AC4: 各判定を外すとテストが落ちる（`verify-by-mutation`）。

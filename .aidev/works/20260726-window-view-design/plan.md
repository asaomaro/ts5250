# 計画: ウィンドウ表示の見せ方

## split 判定

**分割しない**。設定 1 項目＋重ねる描画だけで、単独で検証・デリバリできる単位に割れない。

## 実装方針

**既存の土台に乗せるだけ**にする。窓の検出（`detectWindowRect`）も、設定 UI（`VIEW_ITEMS` の
`expandable`）も、意匠の出し分け（`.pane[data-…]`）も直前の作業で整っているので、
新しく作るのは「矩形 → 重ねる要素」の描画だけ。

1. 設定を足す（`VIEW_ITEMS` に載せるだけで UI とキー順送りが付いてくる）
2. 矩形から重ねる要素を描く（枠 1 枚＋スモーク 4 枚）
3. 意匠の CSS
4. テスト（既定で出ない・両方の窓で出る・桁不変・操作透過）
5. 実機確認（文字の窓＝F1 ヘルプ／拡張5250 の窓＝EXTPGM）

## 作業順序と依存関係

1. T1 設定の追加（依存: なし）
2. T2 描画（依存: T1）
3. T3 意匠 CSS（依存: T2）
4. T4 テスト（依存: T2, T3）
5. T5 実機確認（依存: T3）
6. T6 規約追記（依存: T3）

## リスク / 留意点

| リスク | 対応 |
|---|---|
| 重ねた要素が操作を奪う | `pointer-events: none` を必ず付け、**ビルド後 CSS のガードで固定**する |
| 重なり順で選択・カーソルが隠れる | 文字より上・カーソル/矩形選択より下に置く |
| 窓検出の誤爆で変な位置に出る | 文字・操作は無傷。設定を無効にすれば戻る（spec の異常系どおり） |
| スモークが濃すぎて読めない | 下の画面は「読ませない」のが目的だが、真っ暗にはしない。テーマ変数で調整可能にする |

## テスト方針

- コンポーネント: 既定で要素ゼロ／文字の窓・拡張5250 の窓の両方で出る／窓なしで出ない／
  ON/OFF で行テキストが不変（桁不変）。
- ビルド後 CSS: `pointer-events: none` と、意匠 5 種が定義されていること。
- 実機: F1 ヘルプ（文字の窓）と EXTPGM（拡張5250 の窓）で目視。

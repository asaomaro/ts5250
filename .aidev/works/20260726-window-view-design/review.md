## ラウンド 1（2026-07-26）

観点: requirement の完了条件 / spec との整合 / AGENTS.md（桁不変・意図中心のコメント）/ 正確性。

- **指摘なし（must 0 / should 0 / nit 1）**

- **[nit]** 文字で描かれた窓では、枠の文字（`.` `:`）自体がスモーク側に入る。矩形が
  「枠の内側」を指すため。実機では細い縁として自然に見えており、装飾のためだけに
  矩形を 1 行広げると凡例検出（枠の上に凡例は載らない前提）と食い違うので、そのままにする。
  - 対応: 許容

### 確認して問題なかった点

- **操作を奪わない**: `.win-smoke` / `.win-deco` に `pointer-events: none`。
  ビルド後 CSS のガードで固定した（無いと窓の中がクリックできなくなる重大な壊れ方をするため）。
- **重なり順**: 装飾 z:2（文字より上）、矩形選択 z:3、カーソル z:4。**選択とカーソルは装飾に隠れない**。
- **桁不変**: 絶対配置のみで文字に触れない。ON/OFF で行テキストが不変であることをテストで固定。
- **既定で無効**: `windowView === "none"` のときは `detectWindowRect` を呼ばない（無駄な走査をしない）。
- **矩形の再利用**: 直前の作業の `detectWindowRect` をそのまま使うので、拡張5250 と文字の窓の
  両方に自動で対応する。窓の検出ロジックを二重に持たない。
- **スモークの分割**: 窓の中を覆う矩形が 1 つも無いことをテストで確認（読みやすさを落とさない）。
- 命名は既存の流儀（対象で呼ぶ）に沿う: 「ウィンドウ設定」。

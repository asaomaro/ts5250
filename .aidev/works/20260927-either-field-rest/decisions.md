# 決定記録

## D1: 空にした全角の状態の E 欄の SO の送信は、この work では入れない

- 背景: ACS は `0e` を送り、当 PJ は何も送らない（research F3）。コアの `eitherDbcsOn` だけで SO を置く実装を一度入れたが、独立点検（must）で、画面の側で半角に切り替えてから空にしたときにコアの状態が全角のままなので、ACS が何も送らない場面で `0e` を送る——直す前は正しかった場面を壊すと分かった。
- 決定: 取り下げた。直すには画面の側の状態（`eitherSwitched`）を送る値に載せる（例: SO のセンチネル）作りが要り、web-ui・server・core の 3 つに及ぶ。台帳に測定の事実とともに残す。

## D2: 挿入の貼り付けで E 欄の混ぜる字があれば何も貼らない（ACS と違う）

- ACS は誤りの字でエラーにしてその場で戻り、それまでに挿入した字は残す（research F1）。当 PJ の挿入の貼り付けは他の拒否でも何も貼らない（`20260719-paste-input-validation`）ので、E 欄もその方針に載せた。コメントの「（ACS）」は誤りなので直した。

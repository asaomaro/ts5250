# 要件: VT セッションを Web の画面から使う

## 背景 / 課題

`20260821-vt-terminal-core`（PR #340）で `@ts5250/vt` を作り、**telnet 交渉から画面組み立て・
打鍵まで**が実機で通った（Linux 22/22・pub400 9/9）。しかし **server も web-ui も参照していない**
ので、ブラウザから VT で繋ぐ口が無い。

3270 のときと同じ形——ライブラリを先に仕上げ、次に server と web-ui へ露出する。

## VT は既存のペインに載らない

3270 は `ScreenSnapshot` へ写して**既存の描画をそのまま使えた**。VT は使えない。

| | 5250 / 3270 | VT |
|---|---|---|
| 入力 | フィールド編集 ＋ AID キーで一括送信 | **1 打鍵ごとに送る** |
| 画面 | ホストが丸ごと送る | **流れる**（スクロールバックが本質） |
| 大きさ | 24x80 / 27x132 の固定 | **任意**（NAWS でホストへ伝える） |
| 色 | 7 色 | **256 色・24 ビット色** |
| カーソル | 欄の中を動く | ホストが決める |

`ScreenGrid.vue` は 4,189 行あり、フィールド編集と native caret を単一の真実として組んである。
**VT を混ぜると両方が壊れる。専用ペインを作る。**

## 目的 / ゴール

ブラウザから VT のセッションを開き、**シェルが実用に使える**状態にする。

## スコープ

### 対象

- **server**: VT セッションの保持（`VtManager`）・WS の口・画面の配信
- **web-ui**: 専用ペイン（`VtPane.vue`）——描画・スクロールバック・打鍵・貼り付け・選択とコピー
- **設定**: 端末の種類に `VT` を足す（`terminal: "vt"`）。符号化（UTF-8 / Shift_JIS / EUC-JP）を選べる
- **大きさ**: ペインの寸法から桁・行を測ってホストへ伝える（NAWS）
- **セッション情報**: 種別に「VT端末」を出す

### 対象外

- **マクロ・HLLAPI・PC コマンド・自動サインオン・予約・監視**。いずれも 5250 の
  フィールドモデルに依存しており、VT では意味を持たないか別途の設計が要る（3270 と同じ判断）
- **プリンターセッション**（VT に相当が無い）
- **MCP ツール**（画面の読み取り口。要求が出てから）
- SSH

## 機能要件

- 設定から VT のセッションを作り、ブラウザで開いて**シェルが使える**
- ホストの出力が桁どおりに並ぶ（**全角は 2 桁**）
- **256 色・24 ビット色・下線・反転・太字**が見た目に反映される
- **スクロールバックを遡れる**（ホイール・キー）。**代替画面では遡らない**
- 打鍵がそのまま送られる（`Ctrl` / `Alt` / 矢印 / 機能キー / `Tab` / `Esc`）
- **貼り付け**ができる（bracketed paste に対応）
- 画面の文字を**選択してコピー**できる
- ペインの大きさを変えるとホストに伝わる（`stty size` が追随する）
- IBM i にも Linux にも繋がる

## 非機能要件 / 制約

- **web-ui は `@ts5250/vt/browser` から `import type` する**（`devDependencies`。実行時コードを
  持ち込まない。AGENTS.md「web-ui はホストサーバーの型を実体から import type する」と同じ作法）
- **`tn5250` / `tn3270` / `vt` の相互参照禁止**は維持する。両方を知ってよいのは `server` だけ
- 認可は 5250 / 3270 と同じ枠（所有者検査・readOnly・監査）
- 利用者に見えるメッセージは日本語・です／ます調・句点なし。文言は `opMessages.ts` へ
- **打鍵のたびに画面全体を送らない**。VT は 1 打鍵ごとにエコーが返るので、
  素直に作ると 1 秒間に何十回も全画面を流すことになる
- 秘密情報を成果物・ログに書かない

## 完了条件 (受け入れ基準)

- [ ] ブラウザから Linux の telnetd に繋いでシェルが使える（`ls` / `vi` / `less`）
- [ ] ブラウザから pub400 に VT で繋いでサインオンできる
- [ ] 日本語が桁ずれせず出る。**日本語を打てる**
- [ ] 256 色・24 ビット色が見た目に出る
- [ ] スクロールバックを遡れる。`vi` を開いている間は遡らない
- [ ] ペインの大きさを変えると `stty size` が追随する
- [ ] 貼り付け・選択コピーができる
- [ ] 5250 / 3270 の既存の挙動が変わらない（既存テストが緑）
- [ ] `npm run build` / `npm run lint` / `npm test` が通る
- [ ] 実ブラウザでの検証スクリプトが緑

## 未確定事項

- **打鍵の符号化をどちらでやるか**（ブラウザ側 or server 側）。モード（`DECCKM` 等）は
  server の `VtTerminal` が持つので、**ブラウザは意味のあるキーを送り server が符号化する**方が
  真実が 1 つで済みそうだが、往復が増える。spec で決める。
- **画面の配信形式**。全画面を毎回送るか、差分を送るか。
- **桁・行の測り方**。等幅フォントの実寸をどう得るか（`ScreenGrid` に先例があるか）。

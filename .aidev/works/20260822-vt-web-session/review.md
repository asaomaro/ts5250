# レビュー記録

## ラウンド 1（実ブラウザで通した直後）

### must

- **「ホストがエコーを返していません」が出たまま残る。** 交渉は接続したあとに終わることがあり、
  `vt-opened` の時点の値を握ったままにしていた。→ 変わったときだけフレームに載せ、
  画面に変化が無いときは `vt-echo` で届ける（807513b）。
- **ヘッダーに 5250 専用のボタン（キー・HTML・マクロ）が出る。** どれもフィールドモデルと
  `ScreenSnapshot` の上に建っていて VT に対応するものが無い。押しても何も起きない
  （spec D9 で「出さない」と決めていたのに実装が漏れていた）。→ `activeIsEmulator` から外した。
- **スクロールバックの差分が長さでは取れない。** 上限に達すると `scrollback.length` が
  変わらなくなり「増えていない」と誤読する。→ `@ts5250/vt` に延べ本数（`scrollbackTotal`）を
  足して引き算で出す（18237c0）。**単体テストで先に見つかった**。

### should

- `electron` の配布物の一覧は依存から自動で辿るので `@ts5250/vt` も入るが、期待値を固定して
  いるテストが「増えた」と教えてくれた。→ 期待値を更新。**この種の追随漏れを塞ぐための試験**が
  設計どおり働いた。

### 見送り（記録だけ）

- **履歴は 2,000 行まで DOM に起こす。** それ以上遡りたい要求が出たら仮想スクロールにする。
  ライブラリ側の保持は 1,000 行が既定なので、今のところ全部載る。
- **選択・コピーはブラウザ既定に任せている。** 矩形選択は作っていない（要求が出てから）。
- **マウス報告は経路を通してあるが、ペインからは送っていない。** アプリ（`vim` のマウス操作）が
  要求したときに繋ぐ。プロトコル側は実装済み。
- **IBM i は NAWS を無視して 24x80 で描く**（実測）。ペインが広いと下が余る。
  ホストの仕様なのでクライアントからは動かせない。

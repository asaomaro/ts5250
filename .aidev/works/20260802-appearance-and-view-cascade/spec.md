# 仕様: 「外観」と「表示」に分け、表示設定を 2 段のカスケードにする

## 概要

| いま | これから | 対象 |
|---|---|---|
| `[■] 5250 端末`（`DesignMenu`） | **`[■] 外観`** | アプリ全体 |
| `⚙ 画面`（`ViewSettingsMenu`） | **`⚙ 表示`** | そのペイン |

`表示` の各項目を **`全体の既定` → `このセッション`** の 2 段にする。
既定はすべて「既定に従う」なので、**移行直後の見え方は変わらない**。

## 調査で判明した前提

`:root` は**端末の暗い配色（CRT）をそのまま持ち**、`[data-theme="dark"]` は
**クロームのトークンだけ**を、`[data-theme="light"]` は**端末パレットだけ**を上書きしている。
つまり**どちらのブロックも単体では完結していない**——`:root` の値を前提に差分を当てている。

このままでは `.pane` に `data-theme` を付けても正しく効かない。
例: アプリが light のとき、ペインに `dark` を付けても**端末パレットは root の light を
継承したまま**になり、暗いクロームに明るい画面という壊れた組み合わせになる。

## 設計方針

### 1. テーマのブロックを**自己完結**させる

`[data-theme="dark"]` / `[data-theme="light"]` の**どちらも、クローム＋端末パレットの
全トークンを書く**。`:root` は「属性が無いときの既定」として残す。

選択子から `:root` を外し、**要素を選ばない形**（`[data-theme="dark"]`）にする。
特定度は `:root` と同じ (0,1,0) で、記述順が後なのでルートでの優先関係は変わらない。

これで**同じブロックをペインにも当てられる**ようになる。

### 2. セッション個別のテーマは `.pane` に属性で流す

`EmulatorPane` の根（`.pane`）に `data-theme` を付ける。効く範囲は**ペインの中だけ**
（利用者の判断）——タブ帯は `.group` の直下で `.pane` の外なので影響しない。

**スキンはセッション個別にしない**（利用者の判断）。スキンはクローム主体で、
ペインの中だけ差し替えても意味が薄い。

個別化するのは**表示モードだけ**で、選べるのは `既定に従う / 通常 / ダーク`。
`システム`（OS 追従）はアプリ側で解決済みの概念なので、セッション側には出さない。

### 3. カスケードの持ち方

```ts
state.defaults:  ViewSettings                              // 全体の既定（localStorage・従来の値）
state.overrides: Record<string, Partial<ViewSettings>>     // セッションごとの上書き
effective(sessionId?) => { ...defaults, ...(overrides[sessionId] ?? {}) }
```

- **上書きは保存しない（メモリだけ）。** セッション ID は接続のたびに変わるので、
  保存しても次の起動では結び付かない。既定は従来どおり `localStorage`。
- **既存の保存値は `defaults` として読む。** 移行の手当てはこれだけで済む。

### 4. `表示` メニューの形

```
┌ 表示 ─────────────────┐
│ ［全体の既定］[このセッション]  │  ← 層の切替
│ テーマ    [既定に従う（ダーク）▾] │  ← 継承中は実値を併記
│ SO/SI     [既定に従う] [非表示] [表示] •  ← • は個別指定の印
│ …                              │
│ すべて既定に戻す                │
└───────────────────┘
```

- `このセッション` 層では、各項目の選択肢の先頭に **`既定に従う`** を置く。
- **継承中は実値を併記する**（`既定に従う（CRT）`）。無いと、確かめるのに
  `外観` を開き直すことになる。
- 個別指定した項目には**印**を出す。`すべて既定に戻す` でそのセッションの上書きを一括削除。
- **既定の編集も同じメニュー**（`全体の既定` 層）。別の場所を探させない。

**後のスプールでも同じボタンを出す**ので、項目の一覧は**ペインの種類ごとに差し替えられる**
形にしておく（今回中身を入れるのはエミュレータだけ）。

### 5. `外観` に「タブにシステム名を出す」

- 既定 ON。ON の意味は **「ワークスペース全体で 2 システム以上開いているときだけ出す」**
  （`20260802-tabs-own-system` の挙動そのまま）。OFF なら常に出さない。
- 置き場所は**アプリ全体の設定**なので `外観`。保存は `localStorage`。
- `viewSettings` には入れない——あちらはペインの中の見え方で、こちらはクローム。

## 対象範囲

| ファイル | 変更 |
|---|---|
| `styles.css` | テーマのブロックを自己完結・要素非依存に |
| `stores/viewSettings.ts` | 2 段カスケード。`theme` 項目の追加 |
| `stores/appearance.ts`（新規） | `showTabSystemName`（アプリ全体・localStorage） |
| `components/ViewSettingsMenu.vue` | `⚙ 表示`・層の切替・`既定に従う`・実値の併記・一括解除 |
| `components/DesignMenu.vue` | `外観`・タブのシステム名トグル |
| `components/EmulatorPane.vue` | `.pane` に `data-theme` |
| `components/PaneTabs.vue` | システム名トグルに従う |
| `composables/useTheme.ts` | 解決済みの表示モードを読めるように（併記に使う） |

## インターフェース / データ構造

```ts
// viewSettings
effective(sessionId?: string): ViewSettings;      // 既存の口。中身が本当にセッションを見る
setDefault<K>(key: K, value: ViewSettings[K]): void;
setOverride<K>(sessionId: string, key: K, value: ViewSettings[K]): void;
clearOverride(sessionId: string, key: Key): void; // 「既定に従う」へ戻す
clearAll(sessionId: string): void;                // すべて既定に戻す
isOverridden(sessionId: string, key: Key): boolean;

// 新項目
theme: "light" | "dark";   // 既定は外観の解決値。セッション側は上書きのみ

// appearance（アプリ全体）
showTabSystemName: boolean;  // 既定 true
```

`set(key, value)`（既存）は**全体の既定への変更**として残す——キー設定からの順送り
（`viewSettings.cycle`）が使っており、あれはアプリ全体の操作だから。

## 振る舞いの詳細

- 既定を変えると、**上書きしていないセッションすべて**に効く。
- 個別指定したセッションは既定の変更に**追従しない**。`既定に従う` へ戻せば再び追従する。
- テーマを個別指定すると、**そのペインの中だけ**が変わる（タブ帯・ヘッダーは変わらない）。
- 「タブにシステム名を出す」を OFF にすると、2 システム開いていても名前は出ない
  （色帯は残る——見分けの最後の手段まで消さない）。

## エラー処理 / 異常系

- 上書きを持つセッションが閉じたら、その項目は**捨てる**（メモリだけなので放置でも
  害は無いが、増え続けるのは避ける）。
- 未知のキーが `localStorage` にあっても既定値で埋める（従来どおり）。

## 受け入れ基準との対応

| 完了条件 | 満たし方 |
|---|---|
| ボタンが `外観` / `⚙ 表示` | 方針の表 |
| システム名トグル（OFF なら出ない） | 方針 5 |
| 層の切替と既定の波及 | 方針 3・4 |
| 個別指定はそのペインだけ | 方針 3（`effective(sessionId)`） |
| 継承中の実値を併記 | 方針 4 |
| すべて既定に戻す | `clearAll` |
| テーマの個別指定がペインの中だけ | 方針 1・2 |
| 移行前と見え方が変わらない | 既存値を `defaults` として読む。上書きは空で始まる |

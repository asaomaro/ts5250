# 決定記録

## D1: 表示セッションの既定を ACS に合わせる（入れない）

- 背景: keepAlive は常駐プリンターの実測で入れたが、表示セッションでは一時的な回線断でセッションを落とす（F3）。ACS は入れない（F1）。原則 1（ACS が正典）
- 決定: 表示の 5250 は既定で入れない。必要な環境は `keepAlive: true`（セッション設定）
- 代替案: 間隔を長くする（Node は Windows で間隔・回数を変えられない）／アプリケーション層の心拍を送る（ホストへ余計な通信をする。ACS はしない）

## D2: プリンター・3270・VT・ホストサーバーは変えない

- プリンターは無通信が正常な使い方で、15 分で落ちる実測がある。3270・VT は同じ問題を持つ可能性があるが、今回の報告は 5250 の表示で、ACS の 3270 の既定は未確認。実機・原典で確かめてから揃える（別の項目）

## D3: 落ちた後の復旧は変えない

- 使用中の装置に繋ぎ直せない問題（F4）は、そもそも落ちなければ起きない。ACS も同じ装置名なら同じ（ホストが古いジョブを掴んでいる）。今回は落ちる原因を除く

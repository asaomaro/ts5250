# 要件: 欄の外で押した End の行き先を ACS と同じにする

## 背景 / 課題
- 台帳「【まとめ】キー編集の細部」の「欄の外の End」（`20260921-acs-default-keys` で欄の中の End は揃えた）。当 PJ は欄の外の End で最後の入力欄の先頭へ行っていた。

## 目的 / ゴール
- 欄の外の End で、ACS と同じ欄の同じ桁にカーソルが行く状態。

## ユーザーストーリー
- US1: ACS に慣れた利用者として、欄の外で End を押したら ACS と同じ所へ行ってほしい。なぜなら、続けて打つ位置がずれると入力を誤るから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- 5250 のペインの欄の外の End。
### 対象外
- 3270（ACS の 3270 の End は別の処理。従来どおり）。継続欄の中の End（ScreenGrid の欄の中の処理）。

## 完了条件 (受け入れ基準)
- [ ] AC1: 欄の外の End は、カーソルより後で始まる最初の入力欄（継続欄は先頭の区切りだけ。無ければ先頭の入力欄へ巡回）へ行く。
- [ ] AC2: 着いた欄の末尾（入力の直後。最後の桁まで埋まっていれば最後の桁）に置く。
- [ ] AC3: 各判定を外すとテストが落ちる（`verify-by-mutation`）。

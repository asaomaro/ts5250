# 要件: Field Exit・Field± で欄を出る前の検査を ACS と同じにする

## 背景 / 課題
- 台帳「【まとめ】キー編集の細部」の「Field± の ME・MF・入出力欄の検査」「Field Exit 時の検査」。当 PJ は Field Exit・Field± で欄の種類を見ずに
  消去・右寄せして次の欄へ移っていた（MF は欄を出た後の検査で戻すだけ）。

## 目的 / ゴール
- Field Exit・Field± を押したとき、ACS と同じ欄では止まり、同じエラーを出す状態。

## ユーザーストーリー
- US1: 必須入力・入力不可の欄を持つ画面の利用者として、Field Exit で ACS と同じく止めてほしい。なぜなら、止まらないと必須の欄を空のまま先へ進めてしまうから。（受け入れ: AC1, AC2, AC3）

## スコープ
### 対象
- 入力不可（DDS の I）・ME・MF の欄での Field Exit・Field+・Field−。
### 対象外
- 数値専用欄の Field− で最終桁のゾーンを D にすること（表示のコード変換が要る。台帳に残す）。DBCS 欄の SO/SI 上の Field+（エラー 101）。

## 完了条件 (受け入れ基準)
- [ ] AC1: 入力不可の欄では Field Exit・Field± を「この項目はキーボードから入力できません」（ACS 0004）で止め、欄を出ない。
- [ ] AC2: ME の欄で、カーソルが欄の先頭か MDT が無ければ 0021 で止める（値もカーソルもそのまま・エラー状態）。
- [ ] AC3: MF の欄で MDT があり、カーソルが先頭でなく満杯でも空でもなければ、消去・右寄せをせずに欄の先頭へ戻して 0014 で止める。
- [ ] AC4: 各判定を外すとテストが落ちる（`verify-by-mutation`）。

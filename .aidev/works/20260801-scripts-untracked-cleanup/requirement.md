# 要件: 未追跡の実機診断スクリプト 29 本を追跡下に入れる

## 背景 / 課題

`scripts/` に**未追跡の `.mjs` が 29 本**溜まっている。`20260801-sql-lob-failed-state` の
deliver で「`npm run lint` が落ちるが原因は work の外」として申し送った件
（同 work の decisions D4）。より古くは `20260801-backlog-audit/test-result.md` が
「前セッションの置き土産」として同じ lint エラーを記録しており、**少なくとも 2 回持ち越されている**。

放置による実害は 3 つ。

1. **参照切れ**——29 本のうち **8 本は追跡済みファイルから名指しで参照されている**。
   `shot-fkey.mjs` は 3 つの work の `test.md` が「実機で通しで確認した」根拠として挙げているが、
   **リポジトリを clone しても存在しない**。検証の再現ができない
2. **`npm run lint` が落ちる**——エラー 6 件。全部この 29 本の未使用変数。
   「lint は落ちるのが普通」に慣れると、本物の違反を見落とす
3. **消えやすい**——未追跡なので `git clean` で消える。実機でしか採れない手順が失われる

## 目的 / ゴール

29 本を `scripts/` の既存規約（追跡済み 73 本・`scripts/README.md` の一覧）に合わせて整え、
コミットする。**`npm run lint` がリポジトリ全体で通る**状態に戻す。

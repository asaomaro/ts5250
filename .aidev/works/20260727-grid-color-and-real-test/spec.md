# 仕様: グリッド線の色と可変長マイナー構造

## 設計方針

### D1. グリッド線の色は専用の色コード表で引く
DDS リファレンス GRDATR の Table 14 を `GRID_COLOR` として持つ。
5250 の属性バイト（0x20–0x3F）とは**別の符号体系**なので `decodeAttribute` に渡さない。
X'FF'（表示装置の既定）と未知の値は白へ倒す。

### D2. マイナー構造は**先頭の length に従って**読む
Wireshark のディセクタは 10 フィールドで模しているが、実機は 11 バイトで送ってきた。
長さを決め打たず `length` で進めば、**フィールドが増えても位置がずれない**。
足りないフィールドは `GRID_DEFAULT`（0xFF）に倒す。

### D3. 既定へのフォールバックは 2 段
項目が 0xFF（＝既定を使う）なら主構造の値へ。主構造も既定なら描画側で白・実線へ。
DDS の `GRDATR`（既定）と `GRDBOX` の `*COLOR` / `*LINTYP`（個別指定）の関係をそのまま写す。

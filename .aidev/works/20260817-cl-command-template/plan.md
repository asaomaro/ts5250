# 計画

## 分割しない（1 PR）

`packages/hostserver` に 2 ファイル足し、`server` から使える口を 1 つ開けるだけ。

## 順序

1. **`command-template.ts`**——`QCDRCMDD` 呼び出しと XML 解析（型を先に決める）
2. **`command-build.ts`**——組み立てと検証（**純関数**。ここが単体テストの主戦場）
3. **`index.ts`** から公開
4. **実機で確かめる**——`CRTLIB` を組んで作り、読み戻し、消す

## 危ないところ

- **XML の解析**。`hostserver` に XML パーサは無い。**依存を増やさない**——
  属性の形が固定（`Kwd="LIB"`）なので、**正規表現ではなく小さな字句解析**で足りる。
  ただし `<`/`>`/`&` の実体参照は解く必要がある（`Prompt` に `&` が入る）
- **引用の規則**。ここを外すと**静かに違うコマンドが実行される**。実機で確かめる
- **既存の `run()` を壊さない**。今回は足すだけで、既存の経路には触らない

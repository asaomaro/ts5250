# 要件: その他のキーを畳んで出す（修飾キーの組み合わせつき）

## 背景 / 課題

利用者の指示:

> 右下のキー入力ボタンですが、**その他のキーを表示させるボタンを追加**し、クリックすると
> キーが並んだ行が表示されるようにしてください。**attn や sysreq は常時表示のボタンからは削除**
> してください。キー表示欄は、**f1〜f24、attn、sysreq、esc、pagedown、pageup、home、end、
> ctrl、alt** などを配置してください。ctrl や alt は単独では利用せず、ctrl+ファンクションキーや
> alt+ファンクションキーのように利用するので、**ctrl や alt はトグル出来るようにし、
> トグル状態ではファンクションキーだけ有効化**し、ファンクションキーをクリックすることで
> 組み合わせてキー入力できる仕様にしてください。

## 完了条件 (受け入れ基準)

- [ ] 常時行から Attn / SysReq が消え、「その他」ボタンが出る
- [ ] 「その他」で F1〜F24・Attn・SysReq・PageUp/Down・Home・End・Esc・Ctrl・Alt が出る
- [ ] Ctrl / Alt はトグル。**単独では送らない**
- [ ] トグル中は**ファンクションキー以外が無効**
- [ ] 組み合わせが**キーボードで押したのと同じ**扱いになる
- [ ] ビルド・lint・テストが通る

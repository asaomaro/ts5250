# 計画: その他のキーを畳んで出す

1. 既存のキー処理（`useKeymap` / `keybindings`）の作りを読む
2. StatusBar に開閉トグルとキーの一覧を足す
3. 修飾トグルと無効化
4. EmulatorPane に `@combo` を足し、`rawKeydown` へ流す
5. Attn / SysReq を常時行から外す → **それを見ているテストを直す**
6. 撮って確かめる（無効化の実際も数える）

## リスク / 留意点

- **Attn / SysReq を常時行から外すとテストが落ちる**（ボタンを探している）。
  「その他」を開いてから探すヘルパにまとめる。
- Playwright の `hasText` に正規表現を渡すと**空白が正規化されない**
  （複数行のボタンに当たらない）。文字列指定を使う。

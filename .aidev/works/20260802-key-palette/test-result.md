# テスト結果: その他のキーを畳んで出す

| 検証 | 結果 |
|---|---|
| `npm run build`（`vue-tsc` 込み）／ `npm run lint` | 通過 / エラー 0 |
| web-ui 全体 | 1,264 / 1,266（**残り 2 件は既知のフレーキー**・単独では通る） |
| 実機で撮影・確認 | 下記 |

## 実機で確かめたこと

`その他` を開くと F1〜F24 の行と、Attn / SysReq / PageUp / PageDown / Home / End / Esc /
Ctrl / Alt の行が出る。**Ctrl をトグルすると F キー以外が無効**になることを、
無効になったボタンを数えて確認した:

```
無効: ["Attn","SysReq","PageUp","PageDown","Home","End","Esc"]
```

（F1〜F24 は有効のまま。案内「Ctrl ＋ ファンクションキー」も出る。）

## 直したテスト（6 件）

`sysreq-line.test.ts` が Attn / SysReq のボタンを常時行から探していた。
**「その他」を開いてから探す**ヘルパにまとめた——4 か所で同じ手順を書くと、
次に置き場所が変わったときに全部直すことになる。

## 未検証（穴）

- **組み合わせ送信の実結果を実機で見ていない**（`Ctrl+F1` を押して表示コードが切り替わるところ）。
  `rawKeydown` に流しているので、キーボードで押した場合と同じ経路を通る。
- **狭い画面での折り返し**を撮っていない（F1〜F24 が 1 行に収まらない幅では折り返す作りにしてある）。

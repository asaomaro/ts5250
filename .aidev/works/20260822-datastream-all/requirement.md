# 要件: 5250 データストリームの未実装 4 件を片づける

## 背景

`.aidev/backlog/datastream-commands.md` の 4 件は**すべて「実機で届かないので確かめられない」**
で止まっていた。

- `ROLL`(0x23) — 実装は入っているが**未実測**（方向ビットを直したが裏取りなし）
- `READ IMMEDIATE ALT`(0x83) — 2 実装で扱いが割れており入れていない
- `READ SCREEN TO PRINT`(0x66/0x68/0x6A/0x6C) — 原典も未実装
- 未知のコマンドへの負応答 — 形式を実機で確かめられない

## 前提が崩れた

**IBM 自身が 5250 コマンドを発行する API を出荷している**——動的画面管理（DSM）。
`QSYSINC/H(QSNAPI)` を読むと手続きが揃っており、**任意のコマンドバイトを出す口**まである
（`QsnPutInpCmd` / `QsnPutOutCmd` は第 1 引数がコマンドバイトそのもの）。

**「届かないから確かめられない」は誤りだった。こちらから出させればよい。**

## 目的

4 件すべてを**実機で測って**決着させる。届かせて、当方の実装が正しいか／必要かを確かめる。

## 完了条件

- [ ] 4 件それぞれについて、実機のバイト列と当方の挙動が記録されている
- [ ] 応答が要るものは実装し、**ホストが受理することを確かめる**
- [ ] 要らないものは**要らない根拠**が測定で残る
- [ ] 実機で採ったバイト列が回帰資産になっている

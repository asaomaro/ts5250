# 要件: web-ui のテストの不安定さを減らす

## 背景 / 課題

スイート全体を回すと **回ごとに 1〜14 件が入れ替わりで落ちる**。落ちたテスト自身に原因は無く、
単独でファイルを回すと必ず通る。

これは**本物の回帰を隠す**。実際この状態のまま何度も「全部通った」と報告してきた
——落ちても「またフレーキーか」で流れてしまう。

## 目的 / ゴール

**落ちたら本物の回帰だ、と信じられる状態に近づける。**

## スコープ

### 対象

- テスト間の後片付け（マウント・フォーカス・DOM）
- **直したことを回数で測る**（1 回通ったで「直った」と言わない）

### 対象外

- 個々のテストの書き換え（残りは別途）
- 再試行（`retry`）で隠すこと——目的の逆

## 完了条件 (受け入れ基準)

- [ ] 落ちる件数が有意に減っている（**複数回の測定で示す**）
- [ ] 残っているものを、推測ではなく測定で説明できる
- [ ] ビルド・lint が通る

# 要件: AID ボタンをキー名だけにする

## 背景 / 課題

利用者の指摘——「キー名だけにし、キー説明のテキストは削除して。」

```
F1 ヘルプ  F3 終了  F4 プロンプト  F5 更新  F12 取消  ⏎ 実行  Attn 割込  SysReq システム要求
```

説明が並ぶと横幅を食い、**キーの並びが読み取りにくい**。F13〜F24（Shift 側）は元から
名前だけで、そちらのほうが一覧として見やすい。

## 完了条件 (受け入れ基準)

- [ ] 表示がキー名だけ（`F1` `F3` … `Attn` `SysReq`）
- [ ] **説明は失わない**（ホバーで辿れる）
- [ ] ビルド・lint・テストが通る

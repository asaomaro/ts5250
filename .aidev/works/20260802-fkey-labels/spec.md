# 仕様: AID ボタンをキー名だけにする

## 消すのではなく移す

説明は `title`（ホバー）へ回す。**表示から消えても意味が辿れる**ようにする
——初めて触る人が「F4 が何か」を知る手段が無くなると、ボタンがただの記号になる。

```ts
{ key: "F4", label: "F4", hint: "プロンプト" }
```

Attn / SysReq は元から `title` を持っていたので、**説明の語を `title` 側へ寄せた**
（`アテンション（ホストの ATNPGM を呼ぶ）` → `割込（アテンション。…）`）。

## Shift 側は変えない

F13〜F24 は元から名前だけ。今回の変更で**両者の見え方が揃う**。

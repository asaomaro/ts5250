# レビュー: 認証を有効にしたときの確認

## ラウンド 1（自己レビュー）

### この作業そのものが「積み残した確認」の回収である

#258・#259・#260 の 3 回、`should` に「認証を有効にした通し確認」を書いて先送りした。
今回やってみて、**先送りしていた間ずっとプロセスが落ちる状態だった**ことが分かった。

`printer-stop` の `void withAudit` は #254 で入り、**認証オフの実機 E2E は全部通っていた**
——`assertOwner` が全通過するので、拒否の経路に一度も入らなかった。

**「通っている」の範囲を確かめないと、通っていない範囲が見えない。**
認可は「効かない条件を作らないと測れない」種類の性質で、既定の設定（認証オフ）で
いくら実機を叩いても現れない。

### 修正の性格

2 件とも**認可の設計は変えていない**。

- ランチャーの段の移動——「アプリ自身の画面はシステムに依存しない」は元から真で、
  置き場所が間違っていただけ
- `void` → `await`——エラーの流し方の誤りで、認可判定そのものは正しく動いていた

「検証が見つけたものだけ直す」を守れている。

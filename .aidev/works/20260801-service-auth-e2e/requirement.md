# 要件: 認証を有効にしたときのサービスの見え方・操作可否を確かめる

## 背景 / 課題

サービス周りの実機 E2E（#254 / #258 / #259 / #260）は**すべて認証オフ**で走らせてきた。
そこでは `canEditServer` も `assertProfileAccess` も全通過するので、
**認可が効いているかを一度も測っていない**。

利用者の判断は「**一覧は見せる・操作は管理者だけ**」だった。これが本当にそうなっているか、
実物で確かめる。

## 目的 / ゴール

**認可が効いていて、効いたことが利用者に伝わる**ことを実物で示す。

## スコープ

### 対象

1. 一般ユーザーに**一覧が見え**、**操作ボタンが出ない**
2. 一般ユーザーに**失敗の理由が出ない**（文面にサーバーのパスが載りうる）
3. **画面が隠しているだけではない**——WS へ直接送っても**サーバーが断る**
4. 上記を成立させるのに必要な**最小限の修正**

### 対象外

- 認可の設計そのものの変更（既存の層をそのまま使う）
- トークン認証（Bearer）経路の確認

## 機能要件

- 一般ユーザーがログインして**サービス一覧に辿り着ける**
- 状態は見えるが、開始・停止のボタンが出ない
- API を直に叩いてもパス・警告は返らない。**サーバー設定の一覧は 0 件のまま**
- WS へ直接操作を送ると**断られ、断られたことが返る**

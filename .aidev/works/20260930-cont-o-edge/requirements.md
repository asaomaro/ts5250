# 要件: 継続した O 欄の貼り付け（P3）と単独の SO/SI の Delete（d）を ACS と同じにする

紐づく charter ゴール: charter.md なし（`.aidev/backlog/acs-parity.md`「継続した O 欄の残りの差」(c) の P3 と (d)。利用者の指示「上の２項目に対応して」）

## 背景 / 課題
継続した O 欄（CNTFLD の DBCS 欄）で、ACS と当 PJ の違いが 2 つ残っていた。
- 貼り付けで全角が区間の残り桁に入らないとき、ACS は次の区間の頭へ置いて止まる。当 PJ は置かなかった（`20260930-cont-o-nul` D3 で「稀」として実装しなかった）
- 単独の SO/SI で Delete したとき、ACS はどう詰め直すかを測っていなかった（当 PJ は値を変えない）

## 目的 / ゴール
継続した O 欄の鎖が、貼り付けと、単独の SO/SI への Delete・Backspace で、ACS と同じバイト列とカーソルをホストへ送る状態。

## ユーザーストーリー
- US1: CNTFLD の日本語入力欄へ貼り付ける利用者として、全角が区間の残りに入らなくても ACS と同じ位置に字が置かれてほしい。なぜなら貼り付けた結果がホストへ届く値になるから。（受け入れ: AC1, AC2）
- US2: 全角の並びを編集する利用者として、単独の SO/SI で Delete を押したとき、ACS と同じく死んだ桁が整理され、値が変わってほしい。（受け入れ: AC3, AC4）

## スコープ
### 対象
- web-ui: 鎖の貼り付け（`chainPaste`）、単独の SO/SI の Delete（詰め直しは回す）、区間の頭の Backspace が前の区間の単独の SO/SI を消すとき
- ScreenGrid の配線（貼り付け・エラーの操作員メッセージ）

### 対象外（台帳に残す）
- (e) SI が区間の最後の桁のときの全角の挿入・(f) 編集後に死んだ桁を保つ処理（別の work）
- 複数行の貼り付け（従来の経路）

## 完了条件 (受け入れ基準)
- [ ] AC1: 単一行の貼り付けは 1 字ずつの打鍵と同じに鎖の操作を通し、カーソルが最初の区間を出た字で止まる（P1〜P4 が ACS と一致）
- [ ] AC2: 貼った字が今と同じでも欄は MDT になる（打鍵と同じ）。カーソルは動かさない
- [ ] AC3: 単独の SO/SI での Delete は 0065 を出したうえで詰め直しを回す（死んだ桁が無ければ値は同じで MDT のまま、あれば捨てて SI と SO の間を繋ぐ。D1〜D8 が ACS と一致）
- [ ] AC4: 単独の SO/SI の次の Backspace は 0065 で何もしない（MDT にもしない）

## 未確認 / 確かめたいこと
- 0065 の操作員メッセージの文言は ACS の日本語（「画面の保護域にカーソルがある」）と当 PJ（「この位置では操作できません」）で違う（バイト列には出ない。台帳に残す）

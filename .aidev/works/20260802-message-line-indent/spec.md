# 仕様: 操作員メッセージを桁 2 から始める

## 直し方

表示用の文字列の先頭に**空白 1 桁**を足す。

```ts
const shiftedMessage = computed(() => (props.message ? " " + withShiftCodes(props.message) : ""));
```

**SO/SI の差し込みとは別の話なので分けて足す**——あちらは「全角の前後に符号が要る」、
こちらは「行の左端に属性の 1 桁がある」。同じ関数に混ぜると、どちらの都合で足した空白か
読めなくなる。

## 測って確かめる

見た目だけでなく**位置を数える**:

```
padding-left=10  メッセージ左=10  先頭=" {カーソル"
```

`.opmsg` の左端はセルの桁 1 と同じ（10px）で、先頭が空白なので `{` は桁 2。
ホストの行と一致する。

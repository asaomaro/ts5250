# 要件: 表示セッションに関連付けプリンター（IBMASSOCPRT）を申告できるようにする

## 背景 / 課題
- 台帳「【まとめ】telnet・自動サインオン・装置名の差」の低「関連プリンター（IBMASSOCPRT）が未対応」。
- ACS の 5250 表示セッションには「プリンターの関連付け」の設定があり、有効にすると telnet の NEW-ENVIRON で
  `IBMASSOCPRT=<プリンター装置名>` を申告する（`NVT5250` の変数 19。`AssociatedPrinterSession5250`）。
  当 PJ にはこの設定も申告も無く、ACS から移ってきた利用者が同じ構成を作れない。
- 関連付けの指定方法は ACS に 2 つある——**装置名を直接書く**（`5250AssocPrinterDeviceName`）か、
  **プリンターセッションの設定を指す**（`5250PrinterSession`。先にそのセッションを起こして装置名を待つ）。

## 目的 / ゴール
- 表示セッションの設定に関連付けプリンターの装置名を書けば、ACS と同じ形で IBMASSOCPRT が申告され、
  ホストの側でも ACS と同じ結果（ジョブ・装置の印刷装置）になっている状態。

## ユーザーストーリー
- US1: ACS から移ってきた利用者として、表示セッションに関連付けプリンターを設定したい。なぜなら、ACS で
  そうしていたとおりに、対話ジョブの印刷がそのプリンター装置へ出てほしいから。（受け入れ: AC1, AC2, AC3, AC4）
- US2: 運用者として、関連付けを書かない既存の設定では申告が一切変わらないでほしい。なぜなら、既存の接続の
  交渉が変わると装置の割り当てやサインオンが変わりうるから。（受け入れ: AC5）

## スコープ
### 対象
- tn5250: 表示セッションの接続の選択肢に関連付けプリンターの装置名を足し、ACS と同じ条件・位置・形で IBMASSOCPRT を送る。
- server: 表示セッションの設定（サーバー設定・自分の設定の両方）に装置名の項目を足し、接続まで通す。
- web-ui: セッション設定の画面（5250 端末）に入力欄を足す。
- 実機（ACS のコアと当 PJ の両方）で、ワイヤとホスト側の効果を確かめる。
### 対象外
- **プリンターセッションの設定を指す関連付け**（ACS の `5250PrinterSession`。先にプリンターを起こして装置名を待つ・
  表示の切断に合わせてプリンターを止める・最後の表示と一緒に閉じる、を含む）。サーバーのセッション管理を
  またぐ別の機能なので、台帳に別項目として割って続けて扱う。
- 3270 の関連付けプリンター（`termAssociatedPrinter`）。当 PJ の 3270 にプリンターが無い。

## 機能要件
- 装置名が空・空白だけなら申告しない（ACS の条件）。
- 申告は ACS と同じ位置（変数の並びの中の順）と同じバイト列で送る。

## 非機能要件 / 制約
- 利用者の環境の固有名詞（装置名）をリポジトリに書かない。
- 関連付けは信頼設定ではない（パス書き込み・コマンド実行・秘密に触れない）が、個人設定にも置けるかは design で決める。

## 完了条件 (受け入れ基準)
- [ ] AC1: 関連付けプリンターの装置名を渡すと、NEW-ENVIRON の応答に `USERVAR IBMASSOCPRT VALUE <装置名>` が ACS と同じ位置で入る。空・空白だけなら入らない。
- [ ] AC2: 表示セッションの設定（サーバー設定・自分の設定）に装置名を書け、接続時に tn5250 まで渡る（プリンターセッションの設定には無い）。
- [ ] AC3: web-ui のセッション設定（5250 端末）で装置名を入力・保存・再表示できる。
- [ ] AC4: 実機で、ACS のコアと当 PJ が同じ申告をし、ホスト側の結果（ジョブの印刷装置・存在しない装置名のときの扱い）が同じであることを確かめ、記録する。
- [ ] AC5: 関連付けを書かない設定では、NEW-ENVIRON の応答のバイト列が変わらない。
- [ ] AC6: 各判定を外すとテストが落ちる（`verify-by-mutation`）。

## 未確定事項 / 確認したいこと
- ホストは IBMASSOCPRT を受けて何をするか（ジョブの印刷装置・表示装置の記述の PRTDEV）。存在しない装置名では何が起きるか → research で実機に聞く。
- ACS の GUI の既定・入力の正規化（大文字化するか）→ research で原典を読む。

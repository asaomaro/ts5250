# 計画: ヘッダーの追従

## 作業順序と依存関係

1. `App.vue` の監視を書き換える（依存: なし）
2. テストを新しい規則へ（依存: 1）
3. build / lint / スイート（依存: 2）
4. 実機で実ブラウザ検証（依存: 3）

## リスク / 留意点

- **「開いた時点で固定」を壊さないこと。** 監視の元にメニューの状態を織り込むことで守る。
- 既存テスト「開いた時点で、見ているタブのシステムに合わせる」は、
  新しい規則では**前提が成り立たない**（ヘッダーが常に追うので「直前の対象が別」に
  ならない）。名前と中身を新しい規則へ書き換える。

## テスト方針

- 単体: タブの選び替え／ペインの移動で `menuSystem` が変わる。メニュー中は動かない。
- 実ブラウザ（実機）: **タブを押すだけでヘッダーの表示が変わる**ことを文字で確認する。

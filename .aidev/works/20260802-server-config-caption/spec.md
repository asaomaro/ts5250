# 仕様: 「保管場所」という見出しをやめる

## 役割を 3 つに分ける

```
サーバー設定   [トグル]
               管理者だけが参照・編集できる共有の設定です。サービス（常駐）にできるのは
               こちらだけ——プリンターの自動出力・待ち行列の転送も、サーバー設定の…
```

| 要素 | 役割 |
|---|---|
| 見出し | **その設定の名前**（＝カードのチップ・ⓘ と同じ語） |
| トグル | 入り切り |
| 補足 | 入れると何が変わるか |

**チェックの隣に言い直しを置かない。** 見出しが名前を言っているので、
`サーバー設定にする` は同じことの繰り返しになる。

## ⓘ の「区分」は変えない

ⓘ は `区分: サーバー設定 / 自分の設定` という**2 値の読み出し**なので、「区分」で成立する。
フォームの見出し（真偽の設定名）とは役割が違い、値の側で語が揃っている。

## テストの直し方

`保管場所` を文字列で探していた検査は、**見出し（`.cap`）で見る**ように変える
——カード表示には「サーバー設定」のチップが出るので、`w.text()` の有無では判定できない。

# 要件: HLLAPI の Tab・Backtab をペインと同じく ACS の行き先にする

## 背景 / 課題
- 台帳「【まとめ】キー編集の細部」の「HLLAPI の `@B`（Backtab）が継続欄・逆向きのカーソル送りを見ない（ペインの `backtab` は見る。`20260921-home-record-backspace` D5）」。
  HLLAPI の `@T` / `@B` は「次 / 前の入力欄の先頭」へ移るだけで、欄の途中からの Backtab は 1 つ前の欄へ飛び、カーソル送り（FCW 0x88）・継続欄・DBCS の SO を見ていなかった。

## 目的 / ゴール
- HLLAPI で送った Tab・Backtab が、ACS（とペイン）と同じ位置へカーソルを置く状態。

## ユーザーストーリー
- US1: HLLAPI で画面を操作するスクリプトの作者として、`@T` / `@B` の後のカーソルが ACS と同じであってほしい。なぜなら、ACS の HLLAPI 向けに書いた手順がそのまま動いてほしいから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- HLLAPI の Send Key の `@T` / `@B`（サーバー）。行き先の計算は tn5250 の純関数にし、他からも使えるようにする。
### 対象外
- ペインの Tab・Backtab の実装の置き換え（既に ACS と同じ。DOM の事情があるので今は触らない）。

## 完了条件 (受け入れ基準)
- [ ] AC1: Backtab: カーソルの 1 つ手前以前で始まる最後の入力欄の先頭（欄の途中ならその欄の先頭）、欄の先頭でそこへカーソル送りで来る欄があればそちら、無ければ最後の欄へ回り込む。
- [ ] AC2: Tab: カーソルの下の欄のカーソル送りに従い、そうでなければカーソルより後で始まる最初の入力欄、無ければ先頭の欄へ回り込む。どちらも保護欄・継続欄の 2 区間目以降を飛ばし、先頭が SO の DBCS の欄（O を除く）は 1 桁進める。
- [ ] AC3: 各判定を外すとテストが落ちる（`verify-by-mutation`）。

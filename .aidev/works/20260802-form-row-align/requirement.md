# 要件: 設定フォームの見出しが縦に揃わない

## 背景 / 課題

利用者の指摘——「説明ラベルがある影響で項目によって行数が変わってしまう影響で、
**タイトルラベルの高さ座標が揃っていない**」。

`名前 / ホスト / ポート / TLS / 既定 CCSID` が横一列に並ぶが、`TLS` だけ下に
「証明書を検証して接続」という説明を持つ。その結果**その欄だけ 2 行ぶんの高さ**になり、
**説明の無い隣の欄の見出しが下にずれる**。

## 目的 / ゴール

**説明の有無にかかわらず、見出しの高さが揃う。**

## 完了条件 (受け入れ基準)

- [ ] 説明を持つ欄と持たない欄で、見出しの縦位置が一致する
- [ ] 見出しと入力欄は互いに中央で揃ったまま
- [ ] テスト・lint・ビルドが通る

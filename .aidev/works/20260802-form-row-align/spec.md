# 仕様: 設定フォームの見出しが縦に揃わない

## 原因

`.fgrid` は grid で、各 `.row` はその**行で一番高い欄に合わせて伸びる**（`align-items` の既定は
`stretch`）。`.row` 自身も grid で `align-items: center` を指定しているため、
**伸ばされた箱の中で中身が縦中央に浮く**。

説明を持つ欄は 2 行ぶんの高さがあるので、説明の無い隣の欄だけが中央へ落ちてずれる。

```
説明あり:  [見出し] [入力]        ← 1 行目（上）
           [説明        ]        ← 2 行目
説明なし:        （空き）
           [見出し] [入力]        ← 中央に浮く ← ずれ
                 （空き）
```

## 直し方

`.row` に `align-content: start` を足す。**中身を上に詰める**ので、説明の有無にかかわらず
1 行目の位置が揃う。

`align-items: center` は残す——こちらは**各行の中で**見出しと入力欄を互いに中央で揃える指定で、
役割が違う（`align-content` は行そのものの配置）。

## 罫線を入れない理由（利用者の問い）

試作して撮ったところ、**この格子には合わない**と分かった:

- 線が**列ごとに途切れる**（列間の余白で切れるので、行を貫く線にならない）
- **最終行にも線が付く**（ボタンの上に意味のない線）
- 行の途中で列が尽きると**線が中途半端に止まる**（右下が未完成に見える）

連続した罫線にするには表組みか行ごとの入れ物が要り、**構造を変える割に得るものが少ない**
——見出しがずれるという実際の不満は、揃えることで解決している。

# 要件: アプリ名を `ts5250` にする

## 背景 / 課題

利用者の決定。名前の検討経緯:

- 既存の 5250 エミュレータ 20 点超を調査し、**`5250` を名前に入れるのが多数派**と分かった
  （tn5250 / tn5250j / 5250ng / Fusion5250 / FALCON 5250 …）。
- `tn5250j`（tn5250 の Java 版）という**確立した型**があり、`ts5250` は
  「TypeScript 版」として一目で読める。
- `ts5250` / `@ts5250` / `ts5250-web` は **npm・GitHub とも未使用**（実測）。
- 商標は低リスク（`5250` は型番／プロトコル名で、一般的使用が長い）。

却下した案と理由は `.aidev/works/20260802-rename-ts5250/decisions.md` ではなく
本要件に残す——**QPAD**（既存の登録商標。スウェーデンのゲーミング周辺機器）、
**asmr-5250-tools**（`ASMR` は別ジャンルの略語として浸透しすぎている）、
**Glasshouse**（Green Screens.io と発想が近い）。

## 目的 / ゴール

- **識別子を `ts5250` に統一する**（npm スコープ・パッケージ名・利用者に見える名前）。
- **振る舞いは一切変えない**。名前だけの変更であることが差分から分かること。

## スコープ

### 対象

| いま | これから |
|---|---|
| npm スコープ `@ts5250/*`（7 パッケージ） | `@ts5250/*` |
| ルート `as400-web-emulator` | `ts5250` |
| Electron `as400-5250-desktop` | `ts5250-desktop` |
| Electron `productName: AS400 5250 Emulator` | `ts5250` |
| Electron `appId: com.asaomaro.as400-5250` | `com.asaomaro.ts5250` |
| README の見出し | `# ts5250` |

### 対象外

- **`.aidev/works/*` の過去の記録（184 ファイル）は書き換えない。**
  **その時点の事実を書いたもの**なので、後から名前を差し替えると記録が嘘になる。
  リポジトリの既存方針と同じ（`hostserver.md`「その時点の記録なので書き換えていない」）。
- **GitHub のリポジトリ名**（`as400-web-emulator`）。これは PR では変えられない設定変更で、
  外向きの操作になるため**別途確認してから**行う。
- 機能・振る舞い・依存関係。**1 行も動かさない。**

## 機能要件

- `npm run build` / `npm run lint` / `npm test` が**すべて従来どおり通る**。
- 依存の向きを見張るテスト（`dependency-direction` / `import-from-owner` /
  `ebcdic-not-reexported` / `hostserver-not-reexported` / `log-independence`）が
  **新しいスコープ名で機能し続ける**——これらはソースを正規表現で走査しており、
  スコープ名が変われば**検査そのものが空振りしうる**。
- `package-lock.json` が新しい名前で整合していること。

## 非機能要件 / 制約

- 追加の依存を入れない。
- 実機は使わない（名前だけの変更なので、実機で確かめることが無い）。
- 秘密の混入が無いこと（従来どおり機械走査する）。

- [ ] 依存の向きの検査が**空振りしていない**（新スコープを実際に見ている）。
- [ ] `package-lock.json` が整合している。
- [ ] `.aidev/works/*` の過去の記録が**変更されていない**。
- [ ] 利用者に見える名前（README・Electron）が `ts5250` になっている。

# 要件: 最大化・タブ移動でも状態を維持する

## 背景 / 課題

`20260802-keep-pane-state`（#281）で「タブを切り替えても・メニューへ寄っても・システムを
選び直しても状態が残る」ようにした。そのとき**残した制限を 2 つ**報告し、利用者の指示:

> 最大化でも状態を維持するようにしてください。タブを移動しても状態を維持してください。
> リロードは維持されなくて構いません。

残っていた原因は別々:

| 場面 | 原因 |
|---|---|
| **ペインの最大化** | `App` が `workspaceStore.displayRoot()` を描いている。最大化中はそのグループだけを返すので、**描く木が丸ごと入れ替わる**——最大化した側も含めて全ペインが作り直される |
| **タブの移動**（別グループへドラッグ／端に落として分割） | ペインを**そのグループの `WorkspaceNode` が描いている**。移すと移動元でアンマウント・移動先で新規マウントになる |

## 目的 / ゴール

**開いたタブは、どこへ動かしても・どう畳んでも、閉じるまで同じものが生き続ける。**

## スコープ

### 対象
- ペインの最大化（`⛶`）をまたぐ状態の維持。
- タブを別グループへ移す操作すべて——タブ帯へのドロップ（合流・並び替え）、
  端へのドロップ（分割）。
- 上記に伴う、実体（コンポーネント）の置き場所の見直し。

### 対象外
- **リロード（再読み込み）をまたぐ永続化**。利用者の明示（「リロードは維持されなくて構いません」）。
- 5250／プリンターの描き方。状態は `sessionsStore` にあり、移動しても失われない。
- 状態を持たないペイン（サービス一覧・待ち行列監視）の中身。

## 機能要件

- 最大化・解除をしても、**すべてのグループのペイン**が作り直されない。
- タブを別グループへ移しても、**同じコンポーネントのまま**移る（入力・スクロール位置を含めて残る）。
- 分割（端へのドロップ）で新しいグループができても同じ。
- **閉じたら消える**（`onUnmounted` の後片付け＝SQL の結果セット解放）は維持する。
- **一度も開いていないタブは作らない**（遅延マウント）も維持する。
- 見えていないペインに `active=false` が伝わることも維持する。

## 非機能要件 / 制約

- 追加の依存を入れない（Vue の標準機能で組む）。
- 最大化の見た目（1 枚が全面・分割の比率は解除後に戻る）を変えない。

## 完了条件 (受け入れ基準)

- [ ] 2 分割の左右それぞれでタブに入力し、片方を最大化 → 解除しても**両方の入力が残る**。
- [ ] タブを別グループのタブ帯へ落としても入力が残る。
- [ ] タブを端へ落として分割しても入力が残る。
- [ ] 閉じたタブは消える（実体が残らない）。
- [ ] 一度も開いていないタブは作られない。
- [ ] 最大化の見た目が従来どおり（1 枚が全面、解除で比率が戻る）。

## 途中で踏んだこと（記録）

- **Teleport の行き先は `to` が変わったときだけ引き直される。** グループ id を含めた
  セレクタでも足りない（`split` はグループを再利用する）。実要素を渡す（decisions.md D1）。
- **VTU の `mount` は既定で木を document に付けない。** Teleport の行き先が
  `document.querySelector` で見つからず、`[Vue warn] Failed to locate Teleport target` が出る。
  `attachTo: document.body` が要る。
- **Playwright の `dragAndDrop` では落とし場所の判定が走らない**（decisions.md D4）。

## 未検証の穴 / 残した制限

- 実ブラウザで値の保持を追っているのは**データ転送タブ 1 枚**。分割で
  「再利用された側」に残るペインの保持は**単体テストのみ**（上記のとおり、そこが
  いちばん効く検査になっている）。
- **リロードをまたぐ永続化はしない**（利用者の明示: 「リロードは維持されなくて構いません」）。

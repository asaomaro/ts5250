# 仕様

## 測る順

1. **`ENDPCO` は本当に無いのか**——7.3 / 7.5 の両方で `CHKOBJ`
2. **`STRPCO` に終了指定は無いのか**——`retrieveCommandTemplate` で定義を引く
3. コマンドで終わらせる道が無いなら、**セッション側が終わるとき**に出ないかを見る
   - `STRPCO` を 2 回
   - `STRPCO PCTA(*NO)` に切り替える
   - `SIGNOFF`

## 判定

⚠ **手で書き写した 16 進で照合しない**（1 桁ずれても「出なかった」に見える）。
`packages/tn5250` の定数と同じバイト列から組み立てて突き合わせる。

**どの段でも出なければ、それ自体が結論**——「ホスト側からは誘発できない」を
推測ではなく測定で言えるようにする。

# 決定記録

## D1: 「否定応答は要らない」を破棄した

- 証拠: 形式は ACS の原典（F1）。入力コマンドでは返さないとホストが待ち続ける（F3。WSF D9/72 の 0x80）。以前の判断（`datastream-commands.md`）は出力コマンドの
  実測と「形式を確かめられない」に基づいていた。取り消し線で残した。

## D2: ACS が返す他のセンス・コードは入れない

- WTD のオーダーの誤り（`processWriteToDisplay` の 0x10050122 ほか）は、当 PJ の読み手の誤りの扱い（警告して次の ESC から復帰）と対応が一対一でない。
  条件を一つずつ突き合わせずに入れると、ACS が返さない所で否定応答を返しかねないので、台帳に残した。

## D3: 否定応答は退避の応答の後、Query 等の応答の前に送る

- ACS は同じレコードの中の応答を処理の途中で送り、否定応答を最後に送る。当 PJ は読み手が否定応答の所で止まるので、両方が載るのは誤りの前に Query があるときだけ（実機では未観測）。

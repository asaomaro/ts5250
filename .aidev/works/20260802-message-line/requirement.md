# 要件: 操作員メッセージを画面の最下行へ（＋ヘッダーの製品名を外す）

## 背景 / 課題

利用者の指摘（ACS の画面との比較つき）:

> ACS はクライアント側のエラーメッセージとホスト側のエラーメッセージを**エミュレータ画面の
> 最下行**に配置しているので同じ仕様に合わせてください。ホスト側のエラーメッセージがある状態で
> クライアント側のエラーメッセージを表示させると、クライアント側のエラーメッセージを表示させ、
> クリアされると元々のホスト側のエラーメッセージを表示する仕様で同居させているようです。

> ヘッダーの `5250 Web エミュレーター` がヘッダーの早期の折り返しを誘発しているので削除してください。

**同居のしかたは既に正しかった**（`StatusBar.vue` がクライアント優先・消えたらホストへ復帰を
実装済み）。**置き場所だけが違った**——画面の外（ステータスバー）に、しかも赤字で出していた。

## 目的 / ゴール

**ACS と同じ場所・同じ見た目にする。** ヘッダーは操作に必要なものだけにする。

## スコープ

### 対象

- 操作員メッセージ（ホスト側 `systemMessage` ／ クライアント側 `notice`）を
  **エミュレータ画面の最下行**へ移す
- ヘッダーから製品名を外す

### 対象外

- 同居の規則そのもの（既に正しい）
- メッセージの文面

## 完了条件 (受け入れ基準)

- [ ] メッセージが画面（`.grid`）の中の最下行に出る
- [ ] **画面本文と字の大きさが揃う**（外に置くと揃わない）
- [ ] クライアント側がホスト側を隠し、消えれば戻る
- [ ] ステータスバーには出さない（2 か所に散らさない）
- [ ] ヘッダーに製品名が無い
- [ ] ビルド・lint・テストが通る

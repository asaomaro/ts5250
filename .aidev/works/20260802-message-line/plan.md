# 計画: 操作員メッセージを画面の最下行へ

1. `EmulatorPane` に `messageLine`（クライアント優先・ホストへ復帰）
2. まず `.screen-wrap` に重ねてみる → **撮って確かめる**
3. 字が揃わないと分かったので `ScreenGrid` の中へ移す（`message` prop）
4. `StatusBar` から外す
5. ヘッダーの製品名を外す
6. 場所を見ていたテストを新しい場所へ（4 ファイル）
7. **実機で撮って確かめる**

## リスク / 留意点

- **外に置くと字が揃わない**（`fontPx` は `ScreenGrid` の中でしか効かない）。
- `SysReqLine` と同じ場所を使うので、開いている間は出さない。
- テストが「ステータスバーに出ること」を見ている。**場所が変わっただけ**なので、
  消さずに新しい場所へ移す。

## テスト方針

- **単体**: 画面の中に出る／ステータスバーには出さない／クライアントがホストを隠す／
  消えれば戻る／どちらも無ければ行を出さない
- **実機**: 実際に保護域で打鍵して撮る

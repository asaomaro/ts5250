# 仕様: 操作員メッセージを画面の最下行へ

## どこに置くか——`ScreenGrid` の中

最初は `EmulatorPane` の `.screen-wrap` に重ねた（`SysReqLine` と同じ置き方）。**撮ったら
字が画面より小さかった**——画面は `ScreenGrid` が `fontPx` を実測して拡縮するので、
外側に置いた要素だけが取り残される。

`ScreenGrid` の `.grid`（`font-size` を持つ要素）の中へ移した。**中に置けば継承する**ので、
桁も行の高さも自動で揃う。ACS では画面の 1 行そのものなので、これが正しい置き方。

```
ScreenGrid
  .grid  ← font-size: fontPx（実測）
    …セル…
    .opmsg  ← position:absolute; bottom:8px（= 下 padding の内側＝最下行）
```

## 何を出すか

```ts
messageLine = クライアント側（notice） || ホスト側（snapshot.systemMessage）
```

**規則は変えない**（`StatusBar` にあったものをそのまま移した）。クライアント側が優先し、
消えれば `systemMessage` が自然に戻る——スナップショットが保持し続けるので、
**復帰のために状態を持つ必要は無い**。

## 見た目

**ホスト側とクライアント側を同じ見た目にする**（ACS はどちらも操作員メッセージとして
同じ行・同じ字で出す）。以前はクライアント側だけ赤字だったが、色を変えると
「アプリが出した警告」と「ホストの応答」が別の種類のものに見える。

背面は画面の地色で塗る——下にある行を隠す（ACS も同じ場所を使う）。

## システム要求行との関係

`SysReqLine` も画面の最下部を使うので、開いている間はメッセージを出さない
（同じ場所を取り合わない）。

## ヘッダー

`5250 Web エミュレーター` を外す。**幅を食うだけで何の操作にもならず**、狭い画面で
ヘッダーを早々に折り返させていた。ここに置くのは「いまどこに繋いでいるか」と操作の入口だけ。

# 決定記録

## D1: SBCS のセッションでも漢字・かなは打った時点で弾く（ACS との差を残す）

- ACS は SBCS のセッションでは何も弾かず、送るときにコードページに無い字を置き換える（research F1）。当 PJ の core は送信時に「CCSID の外の文字」で
  拒否する（F5）ので、打鍵で受け付けると送れない値を作るだけになる。どのフォントでも 2 桁の字（漢字・かな・全角英数）は打った時点で弾く。
- Ambiguous の字でコードページに無いもの（37 の `α` など）は打鍵では通り、送信時に拒否される。ACS との差（受け付けて置き換える）は台帳に残した。

## D2: CCSID が分からないときは従来どおり

- 状態に CCSID が無いとき（古いサーバーなど）は DBCS のセッションと同じ扱い。以前の振る舞いを変えない側に倒す。

## D3: 前の版の「a〜z だけ大文字」を破棄した

- `ScreenGrid.vue` の `inputChar` の「対象は半角 ASCII の a-z のみ」（GNU tn5250 `display.c` の `isalpha` 相当）は、ACS の原典（research F2）と
  実機（F3）で覆った。カタカナ系（930・5026）の全欄の大文字化は a〜z のまま（ACS `CodePage.toUpper` も 290 の a〜z だけ）。

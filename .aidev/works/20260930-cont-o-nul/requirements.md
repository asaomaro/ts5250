# 要件: 継続した O 欄の空き（NUL）と空白（0x40）を区別する（ACS と同じ）

紐づく charter ゴール: charter.md なし（`.aidev/backlog/acs-parity.md`「継続した O 欄の残りの差」(a)(c)。利用者の指示で対応不要から再開）

## 背景 / 課題
ACS は継続した O 欄（DDS の CNTFLD の DBCS 欄など）で、空き（0x00）と空白（0x40）を区別する。詰め直しでは**空白を中身として**最終区間まで押し出し（余地に数えない）、
READ MDT ALT は途中の空きを 00 のまま送る。当 PJ の O 欄の値は両方を半角空白で持ち、末尾の空白を落とし、ALT で途中の空きを 40 で送っていた。
実機の ACS のコアの測定（C09・C10・P4・P7・P8）で実在の差と分かった。

## 目的 / ゴール
継続した O 欄の鎖が、空き・空白の扱い（詰め直しの余地・末尾の空白の送信・ALT の途中の空き）で ACS と同じバイト列をホストへ送る状態。

## ユーザーストーリー
- US1: CNTFLD の日本語入力欄の利用者として、ホストが空白で埋めた欄へ挿入したとき、ACS と同じく空白が後ろへ押し出される（欄が空白で満杯なら 0012）。（受け入れ: AC1, AC2）
- US2: READ MDT ALT で欄を読むアプリの開発者として、途中の空きが ACS と同じ 00 で届いてほしい。（受け入れ: AC3, AC4）

## スコープ
### 対象
- web-ui: 鎖の値に空き（U+0000）を持たせる（`OCell.nul`）。詰め直し・Delete・Erase EOF・貼り付けの結果の空き。ホストが書いた空白と書かなかった桁の見分け
- core: 値の U+0000 を空のセルに、鎖の空白を生バイト 0x40 のセルに（末尾の空白も落とさない）

### 対象外（台帳に残す）
- 継続でない O 欄・J・E の値（空きと空白を区別しない）——E の末尾に打った全角空白はここ
- 貼り付けで全角が区間の残りに入らないとき次の区間へ送る（P3）・単独の SO/SI の Delete で詰め直す（d）・SI が区間の最後の桁のときの全角の挿入（e）・編集の値が消えた後に死んだ桁を保つ（f）

## 完了条件 (受け入れ基準)
- [ ] AC1: 鎖の詰め直しは末尾の空きだけを余地に数え、空白は中身として押し出す（空白で満杯の鎖は 0012。空きなら入る）
- [ ] AC2: 実機の ACS の C01〜C12（READ MDT）が末尾の `40` まで一致する（C09・C10 を含む）
- [ ] AC3: ALT で途中の空きは 00・打った空白・ホストの空白は 40 で送り、末尾の空きは送らず末尾の空白は送る
- [ ] AC4: 貼り付けと同じ文字列の打鍵（P1〜P8。ALT）が ACS と一致する（P3・P4 のカーソルは既知の差）

## 未確認 / 確かめたいこと

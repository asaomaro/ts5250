# 仕様: 表示メニューの整理と、プリンター／スプールへの展開

## 1. 「既定に従う」の廃止と、既定値の印

- `このセッション` 層の選択肢から `既定に従う（…）` のボタンを外す。
- 各選択肢のうち**既定と同じ値**に小さな印（`·`）を添え、`title` で「全体の既定」と説明する。
- **選択の見え方は実効値**（継承中なら既定の値が選ばれて見える）。
- **押したときの意味**:
  - 既定と同じ値 → `clearOverride`（追従へ戻す）
  - それ以外 → `setOverride`
  これが無いと、一度個別指定すると二度と追従へ戻せない（`すべて既定に戻す` しか無くなる）。
- 項目名の横の個別指定の印（`●`）と `すべて既定に戻す` は残す。

## 2. テーマの廃止と巻き戻し

- `ViewSettings` から `theme` を落とす（項目定義・既定値・`syncThemeFromAppearance`）。
- `EmulatorPane` の `.pane` から `data-theme` を外す。
- `styles.css` のテーマのブロックを**元の形へ戻す**——`:root[data-theme="…"]` に戻し、
  自己完結のために複製したトークンを削る。`--sys-*`（システムカラー）は残す。
- `useTheme.appTheme()` は使い道が無くなるので削る。

**なぜ巻き戻すか**: 使う当てが無くなった機構を残すと、「ペインにも当てられる」と誤読される。
`:root` を外した形は特定度も下げるので、必要が無いなら戻すのが安全。

## 3. ボタンの高さ

`.vsm-btn` / `.dz-btn` / `.mcm-btn` の `height` を `.theme-btn` と同じ **22px** にする。

## 4. プリンター／スプールの「表示」

- `ViewSettingsMenu` に **`keys?: Key[]`** を足す（省略時は従来どおり全項目）。
  項目の並びは `VIEW_ITEMS` の順のまま絞るだけ。
- `App.vue` が、アクティブなタブの種類に応じて出し分ける:

| アクティブ | 出す項目 |
|---|---|
| エミュレータ | 全部（従来どおり） |
| プリンター / スプール | **`linkify` と `font`** |

- カスケードの鍵は `sessionId`（プリンターはセッション ID、スプールはタブ ID）。
  どちらも文字列なので `overrides` はそのまま使える。
- 適用:
  - `linkify`: 本文の `<pre>` を `splitLinks` で分け、URL/メールを `<a>` にする。
  - `font`: `--screen-mono` をペインへインライン上書きする（`EmulatorPane` と同じやり方）。

### SO/SI 表示・表示コードを入れない理由

帳票の本文は **SCS の復号を通った Unicode 文字列**として届く。`packages/scs` の
`ScsParser` は **SO/SI（0x0E/0x0F）をシフト状態の切替として消費**し、生バイトは端末に来ない。

- **SO/SI 表示**——印を付ける対象（SO/SI の位置）が、端末に届く時点で残っていない。
- **表示コード**——対の表で読み直すには**生の SBCS バイト**が要る。届くのは復号後の文字。
  なお帳票の復号コードページは**システム設定の `spoolCcsid`** で既に選べる。

どちらも「出すだけ出して効かない」ものになるので**出さない**。
実装するなら SCS の出力にシフト位置を持たせる／生バイトを運ぶ、という別の作業になる。

## 対象範囲

| ファイル | 変更 |
|---|---|
| `ViewSettingsMenu.vue` | 既定の印・押下の意味・`keys` で絞る・ボタン高さ |
| `DesignMenu.vue` / `MacroMenu.vue` | ボタン高さ |
| `stores/viewSettings.ts` | `theme` の削除 |
| `composables/useTheme.ts` | `appTheme` の削除 |
| `styles.css` | テーマのブロックを元の形へ |
| `EmulatorPane.vue` | `data-theme` を外す |
| `App.vue` | プリンター／スプールでも `⚙ 表示` を出す |
| `PrinterPane.vue` / `SpoolPane.vue` | `linkify` と `font` の適用 |

## 受け入れ基準との対応

| 完了条件 | 満たし方 |
|---|---|
| 「既定に従う」が無い | 方針 1 |
| 既定値に印 | 方針 1 |
| 既定と同じ値で追従に戻る | 方針 1（押下の意味） |
| `theme` が無く外観に従う | 方針 2 |
| ボタンの高さが揃う | 方針 3 |
| プリンター／スプールで `⚙ 表示` | 方針 4 |

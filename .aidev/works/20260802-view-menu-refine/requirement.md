# 要件: 表示メニューの整理と、プリンター／スプールへの展開

## 背景 / 課題

`20260802-appearance-and-view-cascade`（#284）に対する利用者の指摘 4 件。

1. **「既定に従う」の選択肢が邪魔**。選択肢を削除し、**既定値に小さく印を付ける**形で示したい。
2. **表示設定からテーマ設定を廃止**し、エミュレータ画面も**仕様変更前と同様に
   外観設定のスキンに合わせる**。
3. **マクロ・表示・外観のボタンが高い**。キー・HTML と高さを合わせたい。
4. **プリンターセッションとスプールにも「表示」ボタン**を追加したい。
   設定値は SO/SI 表示・表示コード・リンク化・フォント。

## 目的 / ゴール

- 表示メニューが**値の一覧だけ**になり、どれが既定かは印で分かる。
- テーマはアプリ全体（外観）の一本立てに戻す。
- ヘッダーのボタンの高さが揃う。
- 帳票を読む画面（プリンター・スプール）でも見え方を調整できる。

## スコープ

### 対象
- 表示メニューの選択肢の作り（「既定に従う」の廃止・既定値の印）。
- `theme` 項目の廃止と、それに伴う CSS の巻き戻し。
- ヘッダーのボタン（マクロ・表示・外観）の高さ。
- プリンター／スプールでの「表示」ボタンと、その設定の適用。

### 対象外
- 外観メニューの中身（スキン・表示モード・タブのシステム名）。
- タブのシステムまわり（#283）。

## 機能要件

### 既定値の示し方
- `このセッション` 層でも**選択肢は値だけ**を並べる。
- **既定と同じ値の選択肢に小さな印**を付ける。
- **既定と同じ値を選んだら「追従」に戻す**（上書きを消す）——これが無いと、
  一度個別指定したら二度と既定に追従できなくなる。
- 個別指定していることは従来どおり項目名の横の印で示し、`すべて既定に戻す` も残す。

### テーマの廃止
- 表示設定から `theme` を落とす。エミュレータ画面は**外観（スキン・表示モード）に従う**
  ——`20260802-appearance-and-view-cascade` の前と同じ状態に戻す。
- そのために入れた CSS の作り替え（テーマのブロックの自己完結化・要素非依存化）も**戻す**。
  使う当てが無くなった機構を残すと、次に読む人が「ペインに当てられる」と誤解する。

### ボタンの高さ
- マクロ・表示・外観を、キー・HTML と同じ高さにする。

### プリンター／スプールの「表示」
- 両ペインがアクティブなときヘッダーに `⚙ 表示` を出す。
- 設定は**ペインの種類ごとに項目を差し替える**（表示メニューは既にその形）。
- カスケード（全体の既定／このセッション）はエミュレータと同じ規則。

## 非機能要件 / 制約

- **できないものを、できたように見せない。** 帳票の本文は SCS の復号を通った
  **Unicode 文字列**として届く（SO/SI は復号時に消費され、生バイトは端末に来ない）。
  したがって SO/SI 表示・表示コードの再解釈は**この経路では実装できない**。
  実装できる項目だけを出す。

## 完了条件 (受け入れ基準)

- [ ] 表示メニューに「既定に従う」の選択肢が無い。
- [ ] 既定値の選択肢に印が付いている。
- [ ] 既定と同じ値を選ぶと追従に戻る（上書きが消える）。
- [ ] 表示設定に `theme` が無く、エミュレータ画面が外観に従う。
- [ ] マクロ・表示・外観の高さがキー・HTML と一致する。
- [ ] プリンター／スプールがアクティブなとき `⚙ 表示` が出て、設定が効く。

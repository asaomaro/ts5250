# 計画: 表示メニューの整理と、プリンター／スプールへの展開

## 実装方針

**巻き戻し（テーマ）→ メニューの作り → 高さ → ペインへの展開** の順。
巻き戻しを先にするのは、`theme` が残ったままメニューの選択肢の作りを変えると、
廃止する項目のために印の実装を悩むことになるため。

## 作業順序と依存関係

1. `theme` の廃止（ストア・ペイン・`useTheme`）と `styles.css` の巻き戻し
2. 「既定に従う」の廃止・既定値の印・押下の意味（依存: 1）
3. ボタンの高さを 22px に揃える
4. `ViewSettingsMenu` に `keys`（項目の絞り込み）（依存: 2）
5. `App` がプリンター／スプールでも `⚙ 表示` を出す（依存: 4）
6. `PrinterPane` / `SpoolPane` に `linkify` と `font` を適用（依存: 5）
7. テスト（依存: 1-6）
8. build / lint / スイート（依存: 7）
9. 実機で実ブラウザ検証（依存: 8）

## リスク / 留意点

- **巻き戻しで見え方を変えない。** `styles.css` を元の形へ戻すので、
  `20260802-appearance-and-view-cascade` で測った基準値
  （画面 `rgb(247, 248, 244)`）と一致することを実機で確かめる。
- **既定と同じ値を押したら追従に戻す**という規則は、知らないと「押しても何も起きない」に
  見える。印の `title` で説明し、テストで固定する。
- プリンター／スプールの `sessionId` は種類が違う（セッション ID / タブ ID）。
  どちらも文字列なので `overrides` は共用できるが、**取り違えないこと**。

## テスト方針

- 単体: 既定の印が付く／既定と同じ値で `clearOverride` になる／`theme` が無い／
  `keys` で絞れる／プリンター・スプールで `⚙ 表示` が出る。
- 実ブラウザ（実機）: **巻き戻しで地色が変わらない**こと（前回の基準値と突き合わせ）、
  ヘッダーのボタンの高さが 5 つとも一致すること。

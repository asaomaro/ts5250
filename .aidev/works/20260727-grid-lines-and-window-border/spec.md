# 仕様: DSPF の罫線（GRDATR/GRDLIN・WDWBORDER）を描く

## 設計方針

### D1. パーサは「可変長」を前提に読む（実機で確定）
原典のフィールド並びは**最長形の定義**であって、ワイヤ上の長さの保証ではない。
主構造・マイナー構造とも `remaining` を見ながら読み、足りない分は既定値に倒す。
（実機は Border Presentation を 5 バイト、グリッド主構造を 5 バイトで送ってきた）

### D2. グリッド線は「箱」を辺に分解して描く
ホストは箱や片側の線をまとめて指定するので、描画しやすいよう
上辺・下辺・左辺・右辺・内部罫線に展開する。線種は CSS の `border-style` に落とす。

### D3. ホスト指定の枠はクライアント設定より優先する
ホストが `WDWBORDER` を出しているなら、それが「実機と同じ見た目」。
色だけの指定なら**既定の字形をホストの色で**描く。指定が無い窓は従来どおり。

### D4. グリッド線は GUI 構造体として持つ
`gui.gridLines` に置き、窓・スクロールバーと同じ扱いにする（退避/復元にも含める）。
消去は「同じ位置・同じ種別」を取り除く（ホストは引いたときと同じ指定で消しに来る）。

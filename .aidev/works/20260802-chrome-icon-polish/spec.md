# 仕様: 印を揃える／ログパネルを画面内オーバーレイより上へ

## 対象範囲と変更内容

| # | ファイル | 変更 |
|---|---|---|
| 1 | `components/DesignMenu.vue` | `<span class="chev">▾</span>` と `.chev` の CSS を削除 |
| 2 | `components/StatusBar.vue` | ログのトグル `▾/▴` → `▼/▲` |
| 2 | `components/SqlPane.vue` | 実行ログのトグル `▾/▴` → `▼/▲`（同じ `.logbtn`。下記） |
| 3 | `App.vue` | HTML 保存ボタン `🖹` → `⬇` |
| 4 | `components/LogPanel.vue` / `components/SqlLogPanel.vue` | `z-index: 5` → `10` |

## 設計方針

### 1. 三角を消す（デザイン切替）

ヘッダーの他のメニュー（⚙ 画面・マクロ）は三角を持たない。**開くことは押せば分かる**ので、
1 つだけ持つ理由が無い。`aria-haspopup="menu"` / `:aria-expanded` は残すので、
支援技術には「開くボタン」だと伝わり続ける。

### 2. 三角を揃える（ログ）

`▴`/`▾`（U+25B4/25BE = SMALL TRIANGLE）と `▲`/`▼`（U+25B2/25BC）は**別の字**で、
字面の大きさが違う。「その他」側（大きい方）に合わせる。

**`SqlPane` の「実行ログ」も直す。** クラス名（`.logbtn`）も字も同じ**同一の部品**なので、
片方だけ揃えると次はそちらが浮く。利用者の画像には出ていないので、報告で明示する。

### 3. 印を揃える（HTML 保存）

`🖹`（PAGE WITH TEXT）は「文書」の印で、操作を表していない。JSONL と同じく
**ファイルを落とす操作**なので `⬇` にする。`title` の説明文は変えない。

### 4. 重なり順（option の▾がログの上に出る）

`.opt-btn`（z-index 6）と `.opt-hints`（7）が `.logpanel`（5）より上だった。
`.grid` は `position: relative` だが `z-index: auto` なので**スタッキングコンテキストを作らない**
——中の z-index が `.screen-wrap` の階層へそのまま出て、ログパネルと同じ土俵で比べられていた。

**`.grid` を `isolation: isolate` で閉じる案は採らない。** 透かし（`.wm`、z-index 2）は
「文字より上・矩形選択(3)/カーソル(4) より下」に**意図して**置かれており、閉じると
透かしがカーソルの上に出て、その意図が壊れる。

よって**ログパネル側を上げる**。画面の中に描くものの最大は `.opt-hints` の 7 なので、
余裕を見て 10 に置き、その根拠をコメントに残す。

## 振る舞いの詳細

- ログを開いている間、画面の中のもの（カーソル・選択・罫線・窓・option の▾とリスト）は
  1 つもログパネルの上に出ない。
- ログを閉じれば元どおり。重なり順以外の振る舞いは変わらない。

## エラー処理 / 異常系

なし（表示のみ）。

## 受け入れ基準との対応

| 完了条件 | 満たし方 |
|---|---|
| デザイン切替に `▾` が無い | `.chev` ごと削除。テストで「ボタンに `▾` を含まない」を固定 |
| `▴`/`▾` が UI から消える | 両ペインを `▲`/`▼` に。テストで両方を見る |
| HTML が `⬇ HTML` | App.vue の文字を差し替え |
| ログパネルが画面内オーバーレイより上 | z-index を 10 に。テストで「`.opt-hints`(7) より大きい」を数として固定 |

# 要件: ヘッダー・フッターの印を揃える／option の▾がログの上に出る

利用者から画像つきで 4 件の指摘。どれも「同じ意味のものが違って見える」または
「重なり順が違う」という、見た目の一貫性の問題。

## 背景 / 課題

| # | 指摘 | 今の状態 |
|---|---|---|
| 1 | **5250 端末ボタンの▼は不要** | デザイン切替ボタンだけ `▾` を持つ。同じヘッダーの ⚙ 画面・マクロには無い |
| 2 | **「その他」の▲と「ログ」の▲が揃っていない** | 「その他」は `▲/▼`（U+25B2/25BC）、「ログ」は `▴/▾`（U+25B4/25BE）で大きさが違う |
| 3 | **HTML はダウンロードなので JSONL と印を揃える** | JSONL は `⬇`、HTML は `🖹`。どちらもファイルを落とす操作なのに別の印 |
| 4 | **option の▾がログパネルの上に出る** | `.opt-btn` は z-index 6、`.logpanel` は 5。ログを開いても画面の▾が透けて見える |

## 目的 / ゴール

同じ意味の操作は同じ印で出し、画面の中に描くものはログパネルより下に沈む。

## スコープ

### 対象
- デザイン切替ボタンの `▾`
- ログのトグルの三角（`StatusBar` の「ログ」／`SqlPane` の「実行ログ`」——**同じ `.logbtn`**）
- HTML 保存ボタンの印
- `.logpanel` と画面内オーバーレイの重なり順

### 対象外
- 印そのものの意匠替え（`⬇` を別の記号にする等）。揃えるだけ。
- ログパネルの中身・振る舞い。

## 機能要件

- デザイン切替ボタンに三角を出さない。
- 「ログ」「実行ログ」のトグルの三角が「その他」と同じ字になる。
- HTML 保存ボタンの印が JSONL 保存と同じ `⬇` になる。
- ログパネルを開いている間、**画面の中に描くものは 1 つもその上に出ない**。

## 完了条件 (受け入れ基準)

- [ ] デザイン切替ボタンに `▾` が無い。
- [ ] `▴` / `▾` が UI から消え、ログのトグルが `▲` / `▼` になる。
- [ ] HTML ボタンが `⬇ HTML`。
- [ ] ログパネルの z-index が画面内オーバーレイの最大値より上。

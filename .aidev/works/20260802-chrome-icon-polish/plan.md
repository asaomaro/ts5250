# 計画: 印を揃える／ログパネルを上へ

## 実装方針

4 件とも独立。上から順に当てて、最後にまとめて検証する。

## 作業順序と依存関係

1. デザイン切替の `▾` を削除（依存: なし）
2. ログのトグルを `▲`/`▼` へ（`StatusBar` と `SqlPane` の両方）（依存: なし）
3. HTML 保存ボタンを `⬇` へ（依存: なし）
4. `.logpanel` / `SqlLogPanel` の z-index を 10 へ（依存: なし）
5. 回帰テスト（依存: 1〜4）
6. build / lint / web-ui スイート（依存: 5）

## リスク / 留意点

- **z-index の数字が散らばる**。スケールを持たない PJ なので、コメントで
  「画面の中の最大は `.opt-hints` の 7」と根拠を残す（これが無いと次に誰かが 8 を足す）。
- `.grid` を `isolation: isolate` で閉じたくなるが、透かしの意図的な重なり順を壊す（spec 参照）。

## テスト方針

- 字の検査は**マウントして文字を見る**（jsdom で足りる）。`▴`/`▾` が UI から消えたことを
  両ペインで確かめる。
- z-index は **scoped CSS のソースを読む**（jsdom は計算しない。`20260802-cursor-pad-offset`
  で作った `grid-overlay-offset.test.ts` と同じ手）。数の大小で固定する。

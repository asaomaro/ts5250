# 要件: 欄の先頭の Backspace を ACS と同じにする

## 背景 / 課題
- 台帳「【まとめ】キー編集の細部」の低「欄の先頭での Backspace」。当 PJ は GNU tn5250 に倣い、前の入力欄の末尾へ移っていた。

## 目的 / ゴール
- 欄の先頭の Backspace で、ACS と同じ結果（カーソル・エラー）になっている状態。

## ユーザーストーリー
- US1: ACS に慣れた利用者として、欄の先頭の Backspace で ACS と同じく止まってほしい。なぜなら、前の欄へ移ると続けて打つ Backspace が前の欄の値を消すから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- SBCS の欄と、行をまたぐ SBCS の欄の並びの先頭。
### 対象外
- DBCS の欄（ACS は原典の手順上 0101 だが、文言と実機を確かめていない。台帳に残す）。

## 完了条件 (受け入れ基準)
- [ ] AC1: 欄の先頭の Backspace は操作員エラー 0005 で、カーソルも値も変わらない（続けて打った文字も受け付けない）。
- [ ] AC2: 欄の途中の Backspace・行をまたぐ欄の途中の区切りの先頭の Backspace は従来どおり消す。
- [ ] AC3: 各判定を外すとテストが落ちる（`verify-by-mutation`）。

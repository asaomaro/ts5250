### 指摘

- **[must] 反転（`.a-r`）で `currentColor` を使っており、反転部分の文字が消える**
  / 対応: **修正済み**（`decisions.md` D6）

  `background:currentColor; color:var(--crt)` を同じルールに書くと、`currentColor` が
  その新しい `color`（地色）に解決され、**背景と文字が同色**になる。web-ui が `--cell`
  変数を経由しているのはこの罠を避けるためだった。移植時に見落とした。

  色 class 側で `--cell` に控え、`.a-r{background:var(--cell)}` に直した。
  **HTML の文字列としては正しく出るので目視しないと気付けない**——CSS の形と
  7 色すべてが `--cell` を持つことをテストで固定した。

- **[nit] 履歴版は JS 無効だと全コマが縦に並ぶ（一瞬すべて見えてから畳まれる）**
  / 対応: **意図的**（`decisions.md` D5）

  初期 `hidden` を付けない選択。「1 コマ目しか見えない」より使えるため。

### 確認した点（指摘なし）

- **描画経路が 1 本**: 単票と履歴が同じ `screenFigure()` を通る。
  テストが「履歴版の出力が単票の画面本体を文字列として含む」ことで**構造的に証明**している。
- **決定的**: 変換関数内に `Date.now()` / `Math.random()` が無い。日時は `meta` で受け取る。
  単票・履歴とも 2 回生成して完全一致をテスト。
- **秘密**: `fields[].value` を一切出力しない。非表示欄はスナップショットの時点で
  `nonDisplay`＝空白になっている。専用テストあり。
- **注入**: エスケープ関数が 1 つで、テキストにも属性値にも同じものを通る。
  `<script>alert("x")</script>` を画面・メタ・title に入れても壊れない。
- **自己完結**: `http`/`src=`/`@import`/`url(`/`<link>` を機械的に検出するテストで固定。
- **桁**: 全角は必ず 2ch の箱（D1）。座標は `ch` と `1.25em` に統一。
  `.grid` に padding を置かないので PR #191 の補正漏れ問題が構造的に起きない（D2）。
- **罫線の幾何**: `research.md` から移植し、箱が閉じること（下辺 `row+height`・
  右辺 `col+width`）と単独罫線の `value1`=繰り返し数をテストで固定。
- **色**: 罫線は `GRID_COLOR`（GRDATR 専用コード）。属性バイトとして解釈していない。
- **桁区切り**: 黄・青緑では出さない（PR #191 の既決事項と一致）。
- **リーク**: `stop()` と `SessionManager.close()` の両方で `off`。テストで購読数を確認。
- **core のピュア層規約**: `screen-html.ts` は `node:*` を import していない。
- **既存ツールの応答形を壊していない**（ツール追加のみ）。

## 追加したテスト

**core `screen-html.test.ts` — 21 件**

- エビデンスとして成立する条件: 決定的／注入されない／外部を参照しない／
  JS を切っても読める／押せる部品を置かない／フィールド値を書かない
- 桁がずれない: 正常な全角は `w`（2ch）・対を失った全角は `h`（1ch）・tail 桁は出さない／
  座標が `ch` と `1.25em` で一貫
- 表示属性: 7 色・反転・下線・点滅／桁区切りは出るが**黄・青緑では出さない**／非表示は伏せる／
  同一属性の連なりを 1 span にまとめる
- 罫線の幾何: **箱が閉じる**（下辺 `row+height`・右辺 `col+width`）／単独罫線は
  `value1`=繰り返し数・`value2`=間隔／色は GRDATR 専用コード
- 履歴: **各コマが単票と同じマークアップを含む**（描画経路が 1 本であることの証明）／
  コマ数と送信キー／空履歴／決定的／外部非参照

**server `screen-recorder.test.ts` — 13 件**

- start するまで購読しない／開始時点の画面を 1 コマ目に／二重 start で購読を増やさない
- **stop で購読を外す（リークしない）**／stop してもコマは捨てない／stop 後は増えない
- 上限を超えたら古いコマから捨てる
- 送信キーを次のコマに添える／キーは 1 コマ限り／記録していないときの `noteKey` は無視
- clear／記録時刻

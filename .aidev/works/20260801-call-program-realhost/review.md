### 確認して問題なしだったもの

- **「エラーが出ない」で満足していない**。`QUSROBJD` は呼んだ対象そのもの
  （`QSYS/QCMD *PGM`）を返すので、**オフセットを間違えれば一致しない**。
  中身の突き合わせまでやっている
- **書式の違う API を 2 つ通した**。1 つだと偶然オフセットが合っている可能性を排除できない
- **副作用が無い**（読み取り専用の API のみ）
- **偽の応答で作った単体テストを足していない**（spec D1）。
  `extractOutputs` は内部関数で、テストするには応答バイトを自分で組み立てることになり、
  **自分の理解を固定するだけ**になる。証拠は実機であり、それはスクリプトとして残っている
- **エラーコード構造の先頭 4 バイトを 0 にしている**。非 0 にするとエラーが構造体に入って
  **メッセージが出なくなり、失敗を見逃す**——原典の作法どおり

# 要件: パンくずの「システム」段の見た目を直す

## 背景 / 課題

`20260802-tabs-own-system`（#283）でパンくず第 1 段に**システムカラーの点**を入れた。
その結果、利用者から画像つきで 3 点の指摘。

1. **`システム:` ラベルと色の点が近い**——間を少し空けたい
2. **`:` は要らない**——色の点が挟まったことで、区切りの役目はそちらが果たしている
3. **システム名の高さが「メニュー」「ワークスペース」より小さく見える**

3 の原因: `SystemDot` は `inline-flex` で、その**ベースラインは最初の子＝色の点**から決まる。
点には文字が無いので、名前の行box が他の段と揃わない。

## スコープ

### 対象
- パンくず第 1 段のラベル・点・名前の並びと余白。

### 対象外
- 色そのもの（パレット・出す場所）。`20260802-tabs-own-system` の判断を変えない。
- 他の段（メニュー・ワークスペース）の意匠。

## 完了条件 (受け入れ基準)

- [ ] ラベルと色の点の間に余白がある。
- [ ] `:` が出ていない。
- [ ] 3 つの段の高さが揃っている（実ブラウザで実測）。

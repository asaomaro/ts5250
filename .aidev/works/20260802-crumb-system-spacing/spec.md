# 仕様: パンくずの段を flex で並べる

## 設計方針

`.crumb` を **`inline-flex` ＋ `align-items: center` ＋ `gap`** にする。

- **高さが揃う**——素のインライン並びだと `SystemDot`（`inline-flex`）のベースラインが
  最初の子（文字を持たない色の点）から決まり、名前の行box が他の段とずれる。
  flex にすれば中身が中央で揃い、段の高さも一致する。
- **`gap` がそのままラベルと点の余白**になる（7px）。
- `:` は文字列から落とす。

`.tabbadge` の `margin-left` は落とす——`gap` と二重に効くため。

## 対象範囲

- `App.vue`（パンくずのマークアップと `.crumb` / `.tabbadge` の意匠）

## 受け入れ基準との対応

| 完了条件 | 満たし方 |
|---|---|
| ラベルと点の余白 | `.crumb` の `gap: 7px` |
| `:` が出ない | 文字列から削除。テストで固定 |
| 段の高さが揃う | `inline-flex` ＋ `align-items: center`。実ブラウザで実測 |

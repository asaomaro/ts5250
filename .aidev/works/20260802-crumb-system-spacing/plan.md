# 計画: パンくずの段を flex で並べる

## 実装方針

`App.vue` の 1 か所。マークアップ（`:` の削除）と `.crumb` の意匠を同時に直す。

## 作業順序と依存関係

1. `:` を落とし、`.crumb` を inline-flex に（依存: なし）
2. `.tabbadge` の `margin-left` を落とす（依存: 1）
3. テスト（`:` が出ないこと）（依存: 1）
4. build / lint / スイート（依存: 3）
5. 実ブラウザで 3 段の高さと余白を実測（依存: 4）

## リスク / 留意点

- `.crumb` は `text-overflow: ellipsis` を持つ。flex にすると効き方が変わるが、
  名前側（`.sysdot-name`）が自前で省略を持つので実害は無い。**実ブラウザで確かめる**。

## テスト方針

- jsdom: `:` が出ないこと（文字列で確認できる）。
- 実ブラウザ: **3 段の高さと上端が一致**すること、ラベルと点の間隔。

## 実ブラウザでの実測（実機）

パンくずの寸法を直に測った（使い捨ての probe。コミットしていない）。

```
crumbs:
  「システム実機」  高さ 27 / 上端 0
  「メニュー」           高さ 27 / 上端 0
  「ワークスペース 1」    高さ 27 / 上端 0
ラベルと色の点の間隔: 7px
```

- **3 段の高さと上端が一致**（指摘 3 の解消）。直す前は `SystemDot` が `inline-flex` で、
  そのベースラインが**最初の子＝文字を持たない色の点**から決まっていたため、
  名前の行box だけが他の段と揃っていなかった。
- ラベルと点の間に 7px（指摘 1 の解消）。
- 画面の絵でも `システム ● 実機 › メニュー › ワークスペース ①` と出て、
  `:` が無いこと（指摘 2）を目視で確認。

## 留意点

`.crumb` は `text-overflow: ellipsis` を持つ。flex にすると効き方が変わるが、
名前側（`.sysdot-name`）が自前の省略を持つので実害は無い——実ブラウザで
はみ出しが起きていないことを確認済み。

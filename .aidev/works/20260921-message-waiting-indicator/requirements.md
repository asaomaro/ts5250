# 要件: メッセージ待ち表示（MW）を出さない

## 背景 / 課題
`*NOTIFY` の待ち行列にメッセージが届いても（SBMJOB の完了など）、表示が出なかった。
当 PJ はオペコード（MESSAGE_LIGHT_ON/OFF）だけを `messageWaiting` に保持し、
**スナップショットにも UI にも出していなかった**。**CC2 のビットも見ていなかった**。

### 原典で確かめたこと
`DS5250.processWCC2`（`javap -c -constants`）:
- 定数 `WCC2_MW_ON = 1` / `WCC2_MW_OFF = 2`
- `cc2 & 0x02` で `ECLOIA.setMsgWaiting(false)`、続けて `cc2 & 0x01` で `setMsgWaiting(true)`
  ——**両方立てば点灯が勝つ**。

## 目的 / ゴール
- **メッセージが届いたことが画面から分かる状態。**

## ユーザーストーリー
- US1: 端末の利用者として、投入したジョブの完了などのメッセージが**届いたことに気づきたい**。
  なぜなら ACS なら OIA に出るのに、当 PJ では何も出ず見逃すから。（受け入れ: AC1, AC2, AC3）

## スコープ
### 対象
- CC2 の MW ビットの解析（`wtd-applier`）／セッションの状態とスナップショット／ステータスバーの表示灯。
### 対象外
- MW を消す操作（利用者がメッセージを見たら消す等）。ホストの指示どおり点灯・消灯するだけ。

## 機能要件
- FR1: CC2 0x01 で点灯、0x02 で消灯。両方なら点灯。
- FR2: MW ビットの無い WTD では**状態を保つ**（消さない）。
- FR3: 点灯中はスナップショットに `messageWaiting: true` が載り、ステータスバーに表示灯が出る。

## 非機能要件 / 制約
- `ScreenSnapshot.messageWaiting` は**点灯時だけ付与**（`AGENTS.md`「オプショナルは存在時のみ付与」）。
- 配色は定義済みの CSS 変数（`docs/UI-DESIGN.md`「生色を避ける」）。表示は日本語。

## 完了条件 (受け入れ基準)
- [ ] AC1: CC2 のビットで点灯・消灯し、両方なら点灯（`wtd-applier` のテスト）。
- [ ] AC2: セッション経由でスナップショットに載り、ビットの無い WTD で消えない（セッションのテスト）。
- [ ] AC3: 点灯中だけステータスバーに表示灯が出る（`StatusBar` のテスト）。
- [ ] AC4: 3 層のつなぎそれぞれを外すとテストが落ちる（`verify-by-mutation`）。

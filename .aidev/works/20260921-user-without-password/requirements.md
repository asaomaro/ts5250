# 要件: パスワードが無いときは USER を送らない（ACS と同じ）

## 背景 / 課題
- 台帳「【まとめ】telnet・自動サインオン・装置名の差」の低。当 PJ は利用者名だけ（パスワード無し）でも NEW-ENVIRON に USER を入れていた。
  ACS は USER をパスワード付きの自動サインオンのときだけ送る。

## 目的 / ゴール
- NEW-ENVIRON の USER の送り方が ACS と同じになっている状態。

## ユーザーストーリー
- US1: ACS から移る利用者として、ACS と同じ申告で繋がってほしい。なぜなら、申告が違うとホスト側の扱いが変わりうるから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- telnet の USER の条件。
### 対象外
- 変数の並びの順（ホストは名前で読む。台帳に残す）。

## 完了条件 (受け入れ基準)
- [ ] AC1: パスワードが無ければ USER を送らない（利用者名・パスワードがそろえば従来どおり）。
- [ ] AC2: 条件を外すとテストが落ちる（`verify-by-mutation`）。

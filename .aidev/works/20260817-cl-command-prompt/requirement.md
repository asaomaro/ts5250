# CL コマンドのプロンプト UI（F4 相当）

## 発端

前作業（`20260817-cl-command-template`）で **コマンド定義（テンプレート）を引ける**ようになった
——キーワード・型・必須・既定値・桁数・許される値が取れる。
**その材料で F4 相当の入力画面を作る**、が今回。

> 併せて教わった資料（`blue-red.ddo.jp` の「Java から RPG や CL を呼び出す」）で裏が取れた:
> jt400 の CL 実行は **`CommandCall.run(文字列)` だけ**で、テンプレートは無い。
> **PCML はプログラム呼び出しのテンプレート**であって CL 用ではない。
> つまり「テンプレートから CL を組む」は jt400 に無く、前作業がその足し前だった、で正しい。
> （PCML に当たるものは `packages/hostserver` の `ProgramArg` と `pgm:` ペインで既にある）

## 今どうなっているか

- **テンプレートは引ける**（`retrieveCommandTemplate` / `buildCommand` / `runCommandTemplate`）
- **UI からは使えない**——ブラウザに CL を打つ場所が無く、`hostserver` は Node の層
- 既存の似た画面: **`pgm:`（プログラム呼び出し）ペイン**——`POST /api/host/program` を叩き、
  引数を型つきで並べて呼ぶ。**同じ形が CL にも要る**

## やりたいこと

**コマンド名を入れると、そのコマンドのパラメータが並んだ入力画面が出て、埋めて実行できる。**

実機の F4 と同じく:

- パラメータごとに**説明（`Prompt`）付きの入力欄**
- **既定値**が分かる（空欄なら既定が効く、と見て分かる）
- **選べる値が決まっているもの**（`Rstd=YES`）は**選択肢**にする
- **必須**が印で分かる
- **組み上がるコマンド文字列がその場で見える**（実行前に確認できる）

## 満たすこと

1. コマンド名からテンプレートを引く口が**サーバーにある**
2. 入力値からコマンド文字列を**組む口がサーバーにある**（引用規則を UI に複製しない）
3. `cmd:` ペインで、**引く → 埋める → 見る → 実行する**が通る
4. **打つ前の検証**（必須の抜け・許されない値・桁溢れ）が UI に出る

## やらないこと（今回）

- **`ELEM` の入れ子**——前作業と同じ範囲（`QUAL` と繰り返しまで）
- **実機の F4 と同じ画面配置**（キーワード順・ページ送り・F9 全パラメータ）——
  まずは 1 画面に必要なものを並べる
- **コマンド名の補完**（`*CMD` の一覧）——別作業

## 受け入れ基準

- `CRTLIB` を引くと **8 パラメータが説明つきで並ぶ**
- `TYPE` が **`*PROD` / `*TEST` の選択肢**になる
- 値を埋めると**コマンド文字列が見える**（`CRTLIB LIB(X) TEXT('a b')`）
- 実行すると**メッセージが返る**（成否と `CPF` の本文）
- 必須を空にすると**実行前に止まる**

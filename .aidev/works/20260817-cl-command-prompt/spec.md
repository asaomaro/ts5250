# 仕様: CL コマンドのプロンプト UI

## 1. サーバーの口（2 つ）

`packages/server/src/host-command.ts`（新規）。`host-program.ts` に倣う。

| ルート | 何をするか |
|---|---|
| `POST /api/host/command/template` | `{ source, command, library? }` → **テンプレート**（型どおりの JSON） |
| `POST /api/host/command/run` | `{ source, command, library?, values }` → **組み立てて実行**。組んだ文字列も返す |

**組み立てをサーバーに置く**（requirement 2）——引用の規則は
`packages/hostserver` の `buildCommand` にしかない。UI 側に写すと**二重管理になり、
片方だけ直る**。UI は「値の入れ物」に徹する。

`/run` は**組んだ文字列を必ず返す**——実行したものが記録に残らないと、
後から「何が走ったか」を追えない。

## 2. UI（`cmd:` ペイン）

`packages/web-ui/src/components/CommandPane.vue`（新規）。`ProgramPane.vue` に倣う。

```
コマンド [CRTLIB      ] ライブラリー [*LIBL] [引く]

  LIB *      ライブラリー          [__________]          ← 必須（*）・桁数 10
  TYPE       ライブラリー種別      [*PROD ▾]  既定 *PROD ← Rstd=YES は選択肢
  TEXT       テキスト記述          [__________________]
  …

  組み上がり: CRTLIB LIB(TESTLIB) TEXT('It''s a test')
  [実行]
```

- **必須**は `*` と色で示す
- **既定値**は欄の脇に出す（**欄には入れない**——空欄＝ホストの既定、が CL の作法）
- `Rstd=YES` かつ `specialValues` があるものは `<select>`。**空の選択肢**も置く（＝既定に任せる）
- `maxValues > 1` は**空白区切りで入れてよい**旨を出す（配列に割るのは今回やらない）
- **組み上がりの文字列を常に見せる**——実行前に目で確かめられるのが F4 の値打ち

## 3. 検証はどこでやるか

**サーバー**（`buildCommand` が投げる）。UI は返ってきたエラーを出すだけ。
UI 側でも「必須が空なら実行ボタンを押させない」程度は出すが、**判定の本体は 1 か所**。

## 4. 対象外の扱い

`ELEM` の入れ子は**入力欄を出さない**——出すと「入れたのに効かない」になる。
代わりに **「この画面では扱えないパラメータ」として名前を挙げる**（黙って落とさない）。

## 決定

- **D1**: 組み立てと検証は**サーバー**。UI に引用規則を写さない
- **D2**: `/run` は**組んだ文字列を返す**。何が走ったかを追えるように
- **D3**: 既定値は**欄に入れない**。空欄＝ホストの既定
- **D4**: 扱えないパラメータは**名前を挙げて出す**。黙って落とさない

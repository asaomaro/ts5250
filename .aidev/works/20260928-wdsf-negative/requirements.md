# 要件: WDSF の構造体ごとの長さ・引数の否定応答を ACS と同じにする

## 背景 / 課題
台帳「WDSF の中の否定応答」。頭の検査（長さ・クラス・型）は揃っているが、構造体ごとの長さ・引数の検査が無く、ACS なら否定応答にする WDSF を当 PJ は受けていた（警告して読み飛ばすか、効かせていた）。

## 目的 / ゴール
構造体の長さ・区画・矩形が崩れた WDSF で、当 PJ がホストへ返す否定応答が ACS と同じ状態。

## ユーザーストーリー
- US1: 画面を組むホストのプログラム（DSM・UIM）の作者として、ACS と同じく崩れた WDSF は否定応答で知らされたい。なぜなら、当 PJ だけ黙って受けるとプログラムの誤りに気づけないから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- 0x50 LL≤20・0x51 LL≤8・0x53 LL≤14 → 0x10050113、0x55 LL<7 か (LL−3) が 4 の倍数でない・0x58/0x5B LL≠6・0x59/0x5F LL≠7・0x60 LL<9 か 12〜17・0x61 LL≠11 → 0x10050110、
  0x60・0x61 の区画が 1 でない → 0x10050112、0x61 の矩形が画面の外・0 → 0x10050151
### 対象外
- マイナー構造体の長さ・選択肢の属性・罫線の値（0x10050150〜152）・構造体が画面の外（0x10050112）・0x54 の CCSID の形・ENPTUI を申告しない ACS の読み飛ばし（台帳に残す）

## 完了条件 (受け入れ基準)
- [ ] AC1: 14 通りの崩れた WDSF が ACS と同じセンスの否定応答になる（単体）。正しい 0x5F・0x61・0x60 は通る
- [ ] AC2: 実機で DSM の WDSFNEG の 15 巡のホストの読みが ACS と同じ（N01〜N14 は CPFA304・N15 は rc=0）

# 要件: 原典（tn5250 / tn5250j）と突き合わせて、未実測の部分を明確にする

## 背景 / 課題

`.aidev/backlog/datastream-commands.md` には「実機で届かなかったので未実測」の項目が並ぶ:
`ROLL`(0x23) の形式・`SAVE PARTIAL SCREEN`(0x03) のパラメータの意味・
`READ IMMEDIATE`(0x72) 等のパラメータ長。

**実機に届かないものは実機では確かめられない。** しかし**原典は読める**——
AGENTS.md の方針も「原典を読む」を実測と並ぶ手段としている。
tn5250（C）と tn5250j（Java）はどちらも 5250 の実装で、
**同じ箇所を 2 つ独立に読めば、片方の書き間違いに引きずられずに済む**。

## 目的 / ゴール

- 未実測の項目を**原典の記述で埋める**（何が確定し、何が残るかを分ける）
- 突き合わせで**食い違いが見つかったら直す**
- 「パラメータ長が分からないから捨てる」の対象を**原典で分かる範囲だけ減らす**

## スコープ

### 対象

- tn5250 / tn5250j の該当実装を読み、当方の実装と 1 つずつ突き合わせる
- 食い違い（＝バグ）の修正と回帰テスト
- パラメータ長が原典で確定したコマンドを「レコードごと捨てる」から外す
- 実機で、直した経路が壊れていないことの確認

### 対象外

- 原典に無い・当方でも届いていないものの推測実装
- `READ IMMEDIATE` の**応答**（形式は原典にあるが、**実機で確かめられない**ので入れない）

## 機能要件

- ROLL の方向・行数・範囲の解釈が原典と一致すること
- `0x13` の扱いが原典と一致すること（**パラメータを読まない**）
- 原典が「パラメータ無し」とするコマンドは、**捨てずに次のコマンドへ進む**
- 実機の QSH（起動・F3 退出）が引き続き通ること

## 非機能要件 / 制約

- **原典 2 つが一致した点だけを「確定」として扱う**。片方だけの記述は「参考」に留める
- 当方の実測（ホストの実際の振る舞い）と原典が食い違う場合は**実測を優先**し、
  食い違いそのものを記録する

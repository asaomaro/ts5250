# 要件: 何も無い状態からサービス開始までを通しで確かめる

## 背景 / 課題

利用者の問い:

> これで、管理者が `.env` や `profiles.json` の用意がない状態で、新規でサーバー側登録の
> サーバーを追加して、サービスとしての利用を開始できるようになりましたか？

`20260801-server-config-bootstrap`（#263）で「選択肢が出ない」は直したが、**その先を通していない**。
途中で 1 か所でも詰まれば「できるようになった」とは言えないので、**端から端まで実物で通す**。

## 目的 / ゴール

`.env` も `profiles.json` も無いところから、**画面の操作だけで**

```
システムを追加（保管場所: サーバー設定）
  → プリンターセッションを追加（サービスとして使う ✅）
    → サービスとして待ち受けが始まる
```

まで到達することを、実機＋実ブラウザで示す。

## スコープ

### 対象

- 通しの検証スクリプト（新規）
- 通してみて詰まった箇所の修正

### 対象外

- 認証を有効にした場合（`20260801-service-auth-e2e` で別途確認済み）
- 待ち行列サービスの通し（プリンターで代表する）

## 完了条件 (受け入れ基準)

- [ ] 空のディレクトリで起動し、master key と設定ファイルが自動で用意される
- [ ] 画面から「サーバー設定」でシステムを作れる（パスワードは暗号化されて保存される）
- [ ] その子にプリンターセッションを作ると「サービスとして使う」の欄が出る
- [ ] 保存しただけでサービスの待ち受けが始まる（再起動しない）
- [ ] サービス一覧に「待ち受け中」で出る
- [ ] 見つかった不具合が直り、再発しないテストがある

## 実機ブラウザ検証（`scripts/verify-browser-sign.mjs`）

実機へ実接続し `TESTLIB/SGNPGM` で端から端まで確認。**9/9 passed**。

```
S 6S0 signed   ->  [-12]      ← Field− の結果。**ホストが負値として受け取った**

A DUP keyword  ->  [ALLDUP]   ← 複写文字 0x1C×6 がアプリへ届いた
```

- 数値欄で `-` を打つと文字として入らず符号桁が `-` になり、右寄せされる（`    12-`）
- `DUP_ENABLE` でない欄では複写キーが効かず操作員メッセージが出る

負値が黙って正値になる不具合で、単体テストでは「符号桁に `-` を置く」ところまでしか見えない。
**ホストが −12 と解釈するかは実機に聞くほかない。**

# 要件: DBCS の端末タイプを ACS と同じく IBM-5555-C01 にする

## 背景 / 課題
- 台帳「【まとめ】telnet・自動サインオン・装置名の差」の DBCS 24x80 の端末タイプ（中・要実測）。ACS は `IBM-5555-C01`、当 PJ は `IBM-5555-G02`
  （PUB400 の総当たりで「C01 は 27x132」と見て採った。`terminal-type.ts`）。

## 目的 / ゴール
- DBCS のセッションでホストに名乗る端末タイプ（＝作られる装置の型番）が ACS と同じになっている状態。

## ユーザーストーリー
- US1: DBCS の利用者として、ACS と同じ型番の装置で繋がってほしい。なぜなら、装置の型番（モデル）を見て動きを変えるホストのプログラムや
  運用の設定が、ACS の利用者と食い違いうるから。（受け入れ: AC1, AC2）

## スコープ
### 対象
- `terminalTypeFor` の DBCS。
### 対象外
- SBCS の端末タイプ（RFC 1205 どおりで ACS と同じ）。

## 完了条件 (受け入れ基準)
- [ ] AC1: DBCS は画面サイズによらず `IBM-5555-C01`（ACS のワイヤと同じ）。
- [ ] AC2: 24x80 のセッションで、C01 に変えても画面が 27x132 にならない・色が落ちない（両方の実機で、*DS4 を持つ STRSEU を含めて確かめる）。

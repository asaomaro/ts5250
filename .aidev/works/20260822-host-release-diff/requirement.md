# 要件: 7.3 と 7.5 で挙動が違う箇所を洗う

## 背景

`.aidev/backlog/hostserver.md` の項目。**気づかないうちに 2 リリースを跨いで検証していた**
——実機は **7.3**、pub400 は **7.5**。

「2 リリースで動いた」ことと「差分を把握している」ことは別。**片側でしか測っていない項目**
（DDM / DTAQ / スプール / MSGW など）は、片側だけの確認で通ったことになっている。

## 目的

**同じことを両方で測って並べる。** 出た差が

- **版数の差**なのか
- **その機械の構成・権限の差**なのか

を区別する。前者なら当方が対応する必要があるかもしれない。後者を版数の差と誤読すると、
無い問題を追うことになる。

## 完了条件

- [ ] 両機で同じ項目を測る手段が**再実行できる形**で残っている
- [ ] 出た差が版数由来か構成由来かまで**切り分けてある**
- [ ] 当方の実装に影響する差があれば**直っている**

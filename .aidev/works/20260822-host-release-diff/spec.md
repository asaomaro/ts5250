# 仕様

## 測る対象

ホストサーバー経由で使っている機能を、両機で同じ手順で叩く。

| 分類 | 項目 |
|---|---|
| 素性 | OS 版数、累積 PTF、システム値（QCCSID / QPWDLVL / QCHRID / QLANGID / QAUTOVRT / QMAXSIGN） |
| SQL | SELECT、非クエリ、往復、**SELECT を非クエリ経路へ流したときの落ち方**、CREATE の SQLCODE、20 行取得の所要 |
| コマンド | CL 実行、**コマンド定義の取得**（`QCDRCMDD`） |
| IFS | 書いて読む（CCSID つき） |
| スプール | 一覧 |
| DTAQ | 作る → 送る → **別接続で読む** |

## 進め方の制約

- **1 項目が失敗しても他を続ける**。差分を洗うのが目的なので、途中で止まると測れない
- ⚠ **pub400 は公開の共有機**。作るものは `QTEMP` と `/tmp` に閉じ、後始末する
- ⚠ **サインオンの失敗は `QMAXSIGN` に数えられる**（実機=3 / pub400=5）

## 差の扱い

出た差は**そのまま「版数の差」と書かない**。ホストのメッセージまで降りて理由を確かめ、
**権限・構成の差はそう書く**。

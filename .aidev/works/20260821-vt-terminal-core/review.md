# レビュー記録

## ラウンド 1（自己レビュー・coding 完了時）

### must

- **代替画面を表示中にリサイズすると、退避してある主画面の行数が合わなくなる**
  （`buffer.ts` の `resize`）。`vi` を開いたまま窓を変えて抜けると、行数の違う画面が戻る。
  → 退避側も同じ行数へ揃えるよう修正（4ead8c7）。単体テストを 2 件追加。
- **行を減らすときに上からだけ捨てていた**（同上）。画面の上の方にしか書いていない状態で
  縮めると、書いた内容だけが消えて空行が残る。
  → カーソルより下を先に捨て、足りなければ上から捨てて履歴へ送る、に変更（4ead8c7）。

### should

- `insertChars` に使われない `removed` が残っていた → 削除。
- `csi()` の既定値ヘルパ `n()` が読めない三項の入れ子になっていた
  → 「0 と省略はどちらも既定」という規格の意図をそのまま書く形に整理。

### 見送り（記録だけ）

- **挿入モード（IRM）で全角を書くとき 1 桁ぶんしか押し出していない。**
  正しくは 2 桁。ただし IRM 自体が実アプリでほぼ使われず（`vi` も `less` も使わない）、
  実機検証でも踏まなかった。**踏んだら直す**。
- **`ED 3`（スクロールバック消去）は履歴だけ消す。** xterm は画面も消す実装があるが、
  規格上は履歴のみ。実害が出るまで規格側に付ける。
- **リサイズ時の行の再折返しをしない**（spec で決めた方針）。xterm は再折返しするが
  実装差が大きく、折り返し直した結果が元と違う方が驚かせる。要望が出たら測ってから変える。

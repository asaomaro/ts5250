# テスト結果: エミュレータ画面の余白を ACS 相当に詰める

| 検証 | 結果 |
|---|---|
| `npm run build`（`vue-tsc` 込み）／ `npm run lint` | 通過 / エラー 0 |
| web-ui 全体 | 1,265 / 1,266（**残り 1 件は既知のフレーキー**・単独では通る） |
| 実機で測定・撮影 | 画面に使える高さ **573 → 598px** |

## 実機の測定

```
前: wrap 589 / grid 586（padding 8px 10px） / font 19px
後: wrap 600 / grid 572（padding 1px 2px） / font 19px
```

**画面に使える高さは 573 → 598px（+25px・4.4%）**。この viewport では
19.93px を整数へ丸めるので font は 19 のままだが、**別の大きさでは 1 段上がる**
（整数フォントは滲みを避けるための既存の判断で、変えていない）。

撮った絵では、余白が詰まって画面が枠いっぱいに広がっている。

## 直した既存テスト（3 ファイル）

マウス座標や期待値に**旧余白の数字**が入っていた。定数から引くようにした:

| ファイル | 中身 |
|---|---|
| `screen-grid.test.ts` | 矩形選択・ダブルクリックの座標（3 か所） |
| `pane-nav.test.ts` | 同（2 か所） |
| `fit-font.test.ts` | 期待値を `GRID_PAD_*` から計算 |

## 未検証（穴）

- **狭いウィンドウでの見え方**を撮っていない（余白を削ったぶん、狭いときほど効く）。
- **分割表示（複数ペイン）**で `.group` の余白を 0 にした影響を撮っていない
  （ペインの枠線が仕切りになるので問題ないはずだが、確かめていない）。

# 要件: メッセージ待ち行列を扱えるようにする

## 背景 / 課題

**IBM i のメッセージ待ち行列に、画面を経由せず触る手段が無い。**

運用自動化で必ず要るのに、いまは 5250 の `DSPMSG` を画面操作するしかない:

- `QSYSOPR` の**照会メッセージに応答**する（テープ装着・用紙交換・確認など）。
  応答しないとジョブが止まったままになる
- 利用者の待ち行列へ**通知を送る**
- 溜まったメッセージを**読む・消す**

grep した限り、`msgq` / `sendMessage` / `replyMessage` に相当するものは**皆無**。

## 目的 / ゴール

**照会メッセージに応答できる。** 併せて、一覧・送信・削除ができる。

## スコープ

### 対象

- **一覧**（待ち行列を指定して読む。照会かどうか・キー・重大度・送信元が分かる）
- **応答**（照会メッセージへ返す）
- **送信**（通知・照会）
- **削除**（キー指定・全消し）

### 対象外

- **プログラムメッセージ**（ジョブの呼び出しスタック。別物）
- メッセージファイル（`*MSGF`）の管理
- 待ち行列そのものの作成・削除（CL でできる）
- メッセージの**待ち受け**（届いたら通知）——これは `WatchPane` の系統で別作業

## 機能要件

- 待ち行列は**ライブラリー修飾**で指定できる（`QSYS/QSYSOPR` 等）
- 一覧は**照会メッセージを見分けられる**（応答すべきものが分かる）
- 応答には**メッセージキー**を使う（同じ本文が複数あっても取り違えない）
- **消すのは明示的な操作**（一覧を読んだだけで消えない）

## 非機能要件 / 制約

- 既存の 3,995 件を壊さない
- **実機で確かめる**（QSYSOPR は共有なので、**自分の待ち行列で試す**）
